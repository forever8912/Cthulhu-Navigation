# 《恐惧之海》项目资料库

克苏鲁题材航海经营游戏的策划、配置、美术参考与评审资料。当前设计方向为微信小游戏版：船舱横剖面经营 + 横版挂机塔防。

## 快速入口

- [文档索引与协作规范](docs/00-项目管理/00-文档索引与协作规范.md)：设计文档总入口、有效性说明、变更影响矩阵与已确认决策。
- [系统总览](docs/00-项目管理/01-系统总览.md)：产品定位、核心循环、系统边界与分期。
- [MVP 方案](docs/01-MVP方案)：首周内容量、配置条目、怪物与最小美术需求。
- [系统设计](docs/02-系统设计)：战斗、探索、船舱、船员、SAN、装备等系统明细。
- [评审记录](docs/04-评审记录)：市场、技术、执行、美术与合规评估。

## 目录说明

```text
docs/       策划文档、评审记录与历史版本
data/       Excel 配置源表、JSON 导出和参考数据
assets/     风格定稿、概念图与生图提示词表
tools/      配置导出与提示词表生成脚本
archive/    原始压缩归档，仅供追溯
```

## 配置导出

首次使用先安装依赖，再运行导出：

```powershell
python -m pip install -r requirements.txt
python tools/配置导出/export_config.py
```

脚本默认读取 `data/配置表`，输出到 `data/配置导出`。

## 版本管理约定

- `docs/00-项目管理/00-文档索引与协作规范.md` 是设计工作的详细导航。
- `data/配置表` 是配置源数据；`data/配置导出` 是程序可读结果。
- `docs/99-历史版本` 与 `archive` 只用于追溯，不作为当前设计依据。
- 本地工作缓存、Office 临时文件和登录会话文件不会提交到仓库。
