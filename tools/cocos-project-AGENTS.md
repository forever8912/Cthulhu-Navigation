## 3. 代码工程硬约束

- 引擎基线：Cocos Creator `3.8.0`；代码使用 TypeScript 严格模式。
- 架构原则：逻辑优先、少量 Prefab；业务逻辑不得依赖 `Node`、`Component` 或场景对象。
- 禁止使用旧版 `cc.*` API；统一使用 Cocos Creator 3.x 模块导入。
- 目标结构：`assets/scripts/{core,logic,view,platform,config}`，美术资源位于 `assets/art`。
- 核心模拟采用固定 `20 Hz` Tick；随机行为必须使用可注入、可复现的种子随机源。
- 数值和内容进入配置层，禁止把可调参数散落硬编码在业务逻辑中。
- 存档必须包含 `saveVersion`，任何结构变化都要提供迁移或明确的兼容策略。
- 平台 API 只能通过 `platform` 适配层访问，核心逻辑不得直接调用平台接口。
- 仅将通过美术验收的资源接入正式运行路径；试验资产与正式资产分离。

## 4. Git 与多 Agent 规则

- 每个并行任务使用独立分支或 worktree；一个文件同一时段只允许一个负责人写入。

- 提交保持单一目的，并写清修改内容、验证结果和影响范围。
- 文档与代码属于两个独立仓库；跨仓库任务分别提交，并在交接中记录两个提交哈希。
- 不得擅自更改远程地址、强推、删除远程分支或发布构建。
