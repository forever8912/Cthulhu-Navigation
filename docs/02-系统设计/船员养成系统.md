# 《恐惧之海》微信小游戏版 - 船员养成系统

> 版本：v2.0（新建）  
> 船员养成 = **属性经验（积累）+ 转职（质变）**，辅以装备与特性（见各自文档）。

## 一、四维属性回顾

| 属性 | 绑定 |
|---|---|
| 力量 | 近战武器伤害（发挥率）、HP 上限、动力舱（全程力量岗） |
| 技巧 | 枪械伤害（发挥率）、暴击率、修理、科技器械、钓鱼、工坊、瞭望、过滤设备 |
| 智力 | 法器魔法伤害、枪械释放效率、魔法器械、种植、医务室 |
| 精神 | 圣典治疗/对亡灵伤害、SAN上限/抵抗/恢复、魔法减伤（魔抗）、忏悔室 |

> 四维的来源、合成公式与派生属性见《角色系统》；本文只负责经验与转职。

岗位效率公式：船员属性 ÷ 岗位需求属性，达标100%，**封顶200%**（见《船舱房间系统》1.4）；战斗房同用此模型，器械效率决定射击间隔。

## 二、属性经验

### 2.1 获取渠道

| 渠道 | 规则 | 速率定位 |
|---|---|---|
| 对应属性房间工作 | 在力量房工作得力量经验、技巧房得技巧经验，以此类推 | 基础（挂机主渠道） |
| 战斗 | 参战得力量经验；操作器械按器械类型得技巧/智力经验 | 基础 |
| 锻炼室 | 安排船员锻炼**玩家指定的属性**，定向加速 | 高效（占人力） |
| 特定道具 | 食物/药剂类道具直接给属性经验（如"深海鱼油"=精神经验） | 补充（消耗品） |

### 2.2 升级曲线
- 每项属性独立经验条，经验满则属性+1
- 单级经验需求递增：经验需求 = 20 × 当前属性值^1.3（基准值，数值策划可调）
- 工作/战斗经验只在"效率达标（≥100%）"时全额获得，未达标按效率比例折算——鼓励把对的人放在对的岗位

## 三、锻炼室（功能房，1.1）

| 项 | 规则 |
|---|---|
| 使用方式 | 拖入船员 → 玩家指定锻炼属性（4选1）→ 船员离岗锻炼 |
| 产出 | 指定属性经验，速率约为岗位工作的2.5倍 |
| 代价 | 锻炼期间船员不产出任何资源、不参与战斗（怪物入侵时自动中断迎战） |
| 升级 | Lv1=1个锻炼位；Lv2=2位+效率+25%；Lv3=3位+效率+50% |
| 联动 | 精神锻炼额外缓慢恢复SAN；力量/技巧锻炼消耗食物+20% |

## 四、转职系统（7档位阶 × 神系职业树）

### 4.1 转职条件（三者齐备）
1. **属性达标**：该档要求的主属性值（见4.3档位表）
2. **转职书**：对应档位与职业的转职书道具
3. **转职任务**：任务内容与**目标职业**强相关（见4.4示例）

### 4.2 神系职业树（核心结构）

多个低级职业指向同一上位神明。职业从神系开始设计，映射世界观旧神（畸变面为剧情彩蛋，船员信仰的是神明正常面）：

| 上位神明 | 世界观映射 | 下辖职业（低→高） | 主属性 |
|---|---|---|---|
| **狩猎之神** | 新增职能神 | 渔夫 → 猎手 → 神猎者 | 技巧 |
| **魔法与知识之神** | 知识神（疯狂智者） | 魔法学徒 / 药剂师 → 秘术师 → 大贤者 | 智力 |
| **锻造之神** | 新增职能神 | 工匠 → 机械师 → 神匠 | 技巧 |
| **海洋之神** | 海洋神（深渊之主） | 水手 → 领航员 / 潜水员 → 海皇 | 精神 |
| **死亡之神** | 死亡神（冥界主宰） | 入殓师 → 通灵者 → 冥语者 | 精神 |
| **光明之神** | 光明神（灼日暴君） | 牧师 → 圣战士 → 日冕圣者 | 精神 |
| **战争之神** | 新增职能神 | 战士 → 角斗士 → 战神 | 力量 |

- 2档转职时选择**低级职业**（如渔夫、工匠、魔法学徒）
- 同系低级职业在高档汇聚，最终指向同一上位神明的神级位格
- 魔法与知识之神下辖**两个**低级职业（魔法学徒/药剂师），体现"多个低级职业指向同一上位神明"

### 4.5 转职技能方向（按神明分系）
| 神明 | 技能方向示例 |
|---|---|
| 狩猎之神 | 弱点识破、对精英/Boss增伤、捕鱼加成 |
| 魔法与知识之神 | 元素爆发、治疗增效、魔晶亲和（消耗降低） |
| 锻造之神 | 器械过载（短时DPS翻倍）、速修、锻造优质率提升 |
| 海洋之神 | 航行提速、打捞加成、落水免疫 |
| 死亡之神 | 死亡船员概率留存（遗体复苏）、对亡灵增伤 |
| 光明之神 | SAN护盾、恐惧光环免疫（自身+邻近船员）、祈祷增效 |
| 战争之神 | 白刃范围横扫、登船怪击退、破甲 |

> 转职技能为**被动或自动触发的主动效果**，不增加玩家操作负担（高频操作仍是拖拽船员；玩家手点只有 2 个全船技能，见《战斗系统》第七章）。被动叠加规则（核心升级 + 3/5/7档新增，满阶4条）与武器主动技能见《技能系统.md》。

### 4.6 与死亡的衔接
- **死亡不追回任何养成资产**（v2.1 修订）：转职位阶、职业、属性、特性、装备全部保留；死亡仅表示"本场战斗离场"
- 复活后 SAN 归 30、HP 回 50%，可立即重新上阵（见《SAN与特性系统》第四章）
- 因此转职书投放**不需要**为"死亡损失"留冗余，可按正常养成曲线给；玩家的转职投入是安全的

## 五、养成节奏目标（数值自检）
1. MVP期：1名船员从0到2档转职 ≈ 2-3天正常挂机+操作
2. 属性经验主渠道是"放对岗位挂机"，锻炼室是追赶/定向补短板手段
3. 转职书投放节奏 > 船员死亡率，避免"养了不敢用"

## A.1 职业表（7 神系 × 晋升链，双属性门槛）

> 核心变更：职业双属性（主属性 + 副属性）；被动移 buff 表，职业表只存挂载的 buff_id。

| 字段 | 类型 | 控制内容 |

| main_attr | [enum] | 主属性：str/int/agi/spr |
| main_attr2 | [enum] | **副属性**：str/int/agi/spr/none（枪械职业主=技巧+副=智力；战士主=力量+副=技巧；部分纯法系副=none） |

## A.2 转职档位表（双属性门槛，与职业无关）

| 字段 | 类型 | 控制内容 |
|---|---|---|
| tier | [int] | 位阶 1~7 |
| tier_name | [string] | 船员/老手/精英/大师/宗师/传奇/神级 |
| attr1_type | [enum] | **第一属性类型**：str/int/agi/spr |
| attr1_require | [int] | 第一属性门槛（20/40/65/90/120） |
| attr2_type | [enum] | **第二属性类型**：str/int/agi/spr/none（主副属性相同则填 none） |
| attr2_require | [int] | 第二属性门槛（15/30/50/75/100） |
| book_item_id | [string] | 转职书物品 id（引用物品表；1档写空） |
| reward_json | [json] | 转职奖励：`{"all_attr":3,"main_attr":0,"skill_slot":0}` |
| release_phase | [enum] | mvp / v1_1 / v2_0 / later |
| desc | [string] | 转职任务说明（引用 4.4 示例，程序侧为任务表 id，占位） |

> 程序校验逻辑：`船员.attr[attr1_type] ≥ attr1_require && 船员.attr[attr2_type]（若≠none）≥ attr2_require`。
> attr1_type/attr2_type 实际值从所选职业职业表读取（class_id 决定双属性类型，档位表只给门槛数值）——这样同一档位不同职业双属性类型不同（战士要力量+技巧；牧师要精神+智力），门槛数值共享。

## A.3 船员生成表（招募 roll 规则，SSOT 见《角色系统》3.1）

| 字段 | 类型 | 控制内容 |
|---|---|---|
| rarity | [enum] | common=普通 / fine=优质 / rare=稀有 / epic=史诗 / legend=传说 |
| weight | [int] | 招募出现权重（沿用旧稀有度概率框架） |
| gender_weight_male | [int] | **男性出现权重**（默认 50） |
| gender_weight_female | [int] | **女性出现权重**（默认 50）；两者归一化 |
| attr_roll_min / attr_roll_max | [int] | 四维每项 roll 区间（4~8，全稀有度相同） |
| main_attr_bonus | [int] | 主属性补正 +0/+1/+2/+3/+4（按该船员归属职业系的 main_attr 补正） |
| trait_pos_count / trait_neg_count | [int] | 初始正/负特性数，**均固定 0**：正面特性唯一来源=战胜 Boss 结算，负面仅由 SAN<30（每章1次）/死亡复活获得（见《SAN与特性系统》3.1） |

> **生成顺序（程序口径）**：① 按 rarity 权重定稀有度 → ② 按 gender 权重定性别 → ③ 按 A.5 名称表取该性别名字（去重）→ ④ 按 A.6 外貌表逐部位 roll 拼接立绘 → ⑤ roll 四维与特性。性别是最前置的开关，名称与外貌都由它决定候选池。

## A.5 船员名称表（随机名称池，男女分列）

> 设计目标：像"人"不像"编号"。名字须与世界观贴合（大海、渔港、蒸汽、异域港口混合），避免纯西式奇幻名。

| 字段 | 类型 | 控制内容 |
|---|---|---|
| name_id | [int] | 唯一 id。号段 1xxx=男 / 2xxx=女 |
| gender | [enum] | male=男 / female=女（与 name_id 号段一致） |
| name | [string] | 完整姓名（含姓氏或绰号），如"老盐巴·杰克""独眼玛莎" |
| style | [enum] | 风格：sailor=水手俚语 / port=港口平民 / noble=没落贵族 / exotic=异域 / cult=邪教余孽。用于按海域/章节筛选候选池 |
| rarity_allow | [list] | 允许出现的稀有度（按\|拆，如 `common\|fine`）；空=不限。稀有名字只给高稀有度船员，拉升辨识度 |
| weight | [int] | 池内权重（同性别同风格内归一化） |
| desc | [string] | 命名出处/彩蛋备注 |

**容量要求**：男 ≥60 条、女 ≥60 条（共 ≥120），保证 10 人队伍重名率可控。
**去重规则**：程序 roll 名时排除"当前队伍与图鉴中已存在"的名字；池子耗尽则允许加罗马数字后缀（如"杰克Ⅱ"）。

## A.6 船员外貌表（像素风部位组合）

> 像素风核心思路：**不整张画立绘，而是逐部位拼装**。每个部位是一张小图，按 layer 叠出完整立绘；同一张部位图通过**调色板换色**产出多个外观，大幅压缩美术量。

### A.6.1 部位拆分与绘制顺序

| 部位 part_type | 号段 | layer | 说明 | 是否必选 |
|---|---|---|---|---|
| skin | 1xxx | 10 | 肤色/体型底（像素小人躯干+四肢） | 必选 |
| face | 2xxx | 20 | 脸型/疤痕/胡茬（覆盖在 skin 上） | 必选 |
| eyes | 3xxx | 30 | 眼睛（含圆瞳/细眼/空洞眼） | 必选 |
| mouth | 4xxx | 35 | 嘴/表情（含烟斗、缺牙） | 必选 |
| hair | 5xxx | 40 | 发型/帽子底（盖住头顶） | 必选 |
| outfit | 6xxx | 50 | 服装（水手衫/皮围裙/长袍） | 必选 |
| accessory | 7xxx | 60 | 配饰（眼罩/耳环/头巾/圣徽） | **可选**（按 accessory_chance） |

### A.6.2 外貌表字段

| 字段 | 类型 | 控制内容 |
|---|---|---|
| part_id | [int] | 唯一 id（号段见上表；part_id 决定 part_type） |
| part_type | [enum] | skin / face / eyes / mouth / hair / outfit / accessory |
| gender | [enum] | male=仅男 / female=仅女 / both=通用 |
| option_name | [string] | 选项名（寸头/马尾/疤脸/独眼…），策划/美术对齐用 |
| asset_path | [string] | 像素图路径（如 art/crew/hair/m_short_01.png） |
| layer | [int] | 绘制层级，同层按 part_id 升序绘制（见 A.6.1） |
| anchor_x / anchor_y | [int] | **锚点偏移**（像素）；保证头身接缝对齐，不同发型高度不同靠此校准 |
| palette_json | [json] | **允许的调色板** `["p1","p3","p5"]`，程序随机选一个做换色；空=不换色。一张图 × N 调色板 = N 种外观 |
| min_rarity | [enum] | 最低稀有度（如伤疤/眼罩只给 rare 以上，强化"老兵感"） |
| weight | [int] | 同 part_type 内权重（归一化） |
| desc | [string] | 美术备注 |

### A.6.3 组合规则（程序口径）

```
roll 外貌(gender, rarity, accessory_chance)：
  for part_type in [skin, face, eyes, mouth, hair, outfit]:
    候选 = 外貌表.filter(type==part_type && gender∈{该性别, both} && min_rarity ≤ 该船员稀有度)
    if 候选空 → 回退 gender=both 的候选
    选中 = 按 weight 加权随机
    if palette_json 非空 → 随机选一个调色板 tint
    记录 part_id + palette_id 到船员实例的 look 数据

  accessory: rand() < accessory_chance ? 同规则 roll 一条 : 跳过

渲染：按 layer 升序绘制所选部位，逐个应用 anchor_x/anchor_y 与调色板
```

**美术量估算**：必选 6 部位 × 男女各约 6~8 选项 ≈ 90 张底图；配饰 20 张。配合 3~5 个调色板，可组合出 **数万种**外观，而美术只需画约 110 张图。

**与像素风的一致性约束**：
1. 所有部位共用同一套像素网格（建议 32×40 或 48×56 画布），不得跨尺寸。
2. 调色板统一由美术给（如 p1 冷灰/p2 暖褐/p3 深蓝/p4 墨绿/p5 酒红），禁止逐图自定义。
3. 描边色固定 1 色（深褐 #2b1d14），保证混搭不割裂。
4. 部位图必须留透明通道，禁止自带背景。
