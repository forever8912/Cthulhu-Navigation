# 《恐惧之海》微信小游戏版 - 海图系统 v3.0

> 版本：v3.0（2026-10-28 **整篇重写**）
> **旧版已作废**：v1 的"探索度 0~100%""金币购买海图""6 张海图各 1 章"三套结构与现行的"距离推进 + 航段 + 深度层"模型冲突，全部删除。
> 现行口径：**海域 = 一条有固定长度的航线**（第一章 1,000 里 / 第二章 3,000 里 / 第三章 5,000 里），推进距离即进度，Boss 在终点。

## 二、航段（检查点）

长章节必须能中断，否则 83 分钟一章没人打得完。

| 项 | 规则 |
|---|---|
| 段长 | **每 500 里 1 段**（第一章 2 段 / 第二章 6 段 / 第三章 10 段） |
| 段内时长 | ≈ 8.3 分钟 |
| 自动存档 | 完成一段，写入"已抵达航段 N" |
| 主动抛锚 | 任意时刻可点，进度存到**当前航段起点** |
| 下线 | **自动抛锚**，存到当前航段起点 |
| 战败 | 回退到**当前航段起点**（不是整章重置） |
| 已通关航段 | 可"全速航行"跳过，节省 60% 时间（重刷用） |

> **段长为什么是 500 里而不是 1,000 里**：8.3 分钟正好是"一次上线推 2~4 段 = 17~33 分钟"的合理 session 粒度。1,000 里一段会让单次上线只能推 1 段，碎片时间利用不充分。

## 三、海域属性（替代旧"探索度"）

| 属性 | 说明 |
|---|---|
| 名称 | 海域名 |
| 总距离 | 航段数 × 500 |
| 难度系数 | 查《怪物系统》第二章海域参数表（D_r / HP / 攻击） |
| 恐惧基准 | 查《SAN与特性系统》麻木模型表 |
| 掉落组 | 查《怪物系统》5.2（按海域序号，不按深度层） |
| 事件池 | 该海域的岛屿/漂流物/海面奇遇池（见《03-MVP内容配置表》§三、§四） |
| 里程碑表 | 该海域的精英/小Boss/Boss 固定距离点（见《探索与事件》A.3.2~A.3.4） |

**❌ 已删除的旧字段**：探索度百分比、探索度等级称号、探索度奖励阶梯、"海图"作为可消耗道具。这些是回合制"一关一图"的遗留，与距离推进模型不兼容。

## 四、海域切换

| 项 | 规则 |
|---|---|
| 已解锁海域 | 可随时在"航海图"界面切换出发 |
| 切换代价 | **无代价**，但会重置到该海域的**第 1 航段** |
| 进度保留 | 各海域进度独立保存，切走不丢 |
| 重刷 | 已通关海域可重刷，**掉落不衰减**（支持"打不过就回刷"） |
| 推荐提示 | 界面显示"推荐 D_r"，玩家当前 D_r 低于推荐值 80% 时标黄警告 |

> **无代价切换是刻意的**：本作的核心正循环是"打不过 → 回低级海域刷资源 → 再来"。任何切换代价都会打断这个循环，把小挫折变成墙。

## 五、奇迹之海（无限模式）

| 项 | 规则 |
|---|---|
| 解锁 | 通关海域3（击败灼日暴君投影） |
| 地形 | **循环复用海域1~3 的地图资源**：层1 用海域1 池、层2 用海域2 池、层3 用海域3 池、层4 回到海域1，依此类推 |
| 层长度 | 每层 **1,500 里**（≈25 分钟） |
| 深度层 | `layer = floor(累计里程 ÷ 1500) + 1` |
| 怪物数值 | 层 n 查海域参数表第 n 行；n>6 用 `1.75^(n-1)` 公式外推（见《怪物系统》2.3） |
| 掉落组 | **按层对应海域结算**（层7 用海域1 的掉落），不随层数膨胀 |
| Boss | 每层中点 1 小Boss、层末 1 大Boss |
| 中断 | 每 500 里一航段，与主线一致 |
| 战败 | 只回退到最近航段，**不重置层进度**（这是无限模式能反复刷的前提） |
| 收束 | 层 10 之后**不再加数值层**，收益转为排名积分（见《怪物系统》2.3） |

> **深度层是"无限内容"的唯一低成本解法**：不新增美术、不新增关卡，只靠一个变量驱动数值成长。玩家在层 8 面对的是"数值=海域8、模型=海域2"的怪——感知上是"更深的海，同样的东西变得更可怕"，这恰好符合克苏鲁的恐怖逻辑。

## 六、里程榜

| 项 | 规则 |
|---|---|
| 榜维度 | 累计航行里程 + 玩家所属地区 |
| 结算 | 按周 |
| 奖励 | 前列获得贝壳币 / 限定外观 / 橙装碎片 |
| 计入范围 | 主线 + 奇迹之海 + 重刷，全部计入 |
| 反作弊 | 里程由服务端校验（仅榜单一处需要联网，其余全离线） |

> 这是本作**唯一的联网要素**。单机定位不变——玩家不联网也能完整游玩，只是不上榜。
