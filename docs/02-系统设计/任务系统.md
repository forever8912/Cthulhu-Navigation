# 《恐惧之海》微信小游戏版 - 任务系统设定

## 一、任务概述

任务系统是游戏的核心引导机制，通过任务引导玩家探索海域、提升实力、推进剧情。任务分为主线任务、支线任务和每日任务三种类型。

## 二、任务类型

### 1. 主线任务

#### 特点
- 一次性任务，完成后不再刷新
- 推动游戏剧情发展
- 奖励丰厚，包含贝壳币、经验、资源等

#### 主线任务流程

| 任务名称 | 触发条件 | 目标 | 奖励 |
|----------|---------|------|------|
| 初出茅庐 | 登录游戏 | 完成首次航行 | 金币×500、初始海图×1 |
| 迷雾探索 | 完成初出茅庐 | 迷雾海峡探索度达到30% | 金币×800、神秘碎片×5 |
| 翡翠之旅 | 迷雾探索完成 | 解锁翡翠海域并探索 | 金币×1000、新海图×1 |
| 风暴挑战 | 翡翠之旅完成 | 风暴洋探索度达到50% | 金币×1500、史诗装备×1 |
| 深渊探秘 | 风暴挑战完成 | 深渊海域探索度达到50% | 金币×2000、传说装备×1 |

### 2. 支线任务

#### 特点
- 每日刷新，可重复完成
- 补充主线任务的额外奖励
- 任务目标多样化

#### 支线任务类型

| 任务类型 | 示例 | 奖励 |
|----------|------|------|
| 战斗任务 | 击败5只怪物 | 金币×200、材料×10 |
| 探索任务 | 探索2个岛屿 | 金币×150、补给×5 |
| 收集任务 | 收集10个木材 | 金币×100、神秘碎片×2 |
| 营救任务 | 解救3名幸存者 | 金币×250、船员经验×50 |

### 3. 每日任务

#### 特点
- 每日0点刷新，数量有限
- 任务简单，奖励稳定
- 完成所有每日任务有额外奖励

#### 每日任务列表

| 任务名称 | 目标 | 奖励 |
|----------|------|------|
| 日常航行 | 完成1次航行 | 金币×100 |
| 海上猎杀 | 击败3只怪物 | 金币×150 |
| 物资收集 | 获得任意物资5次 | 金币×100 |
| 任务达人 | 完成3个任务 | 金币×200 |

#### 每日任务额外奖励
- 完成全部4个每日任务：金币×500、高级口粮×5

## 三、任务目标类型

### 目标类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 航行任务 | 完成指定次数航行 | 完成3次航行 |
| 探索任务 | 达到指定探索度 | 探索度达到50% |
| 战斗任务 | 击败指定数量敌人 | 击败10只怪物 |
| 收集任务 | 收集指定物品 | 收集20个木材 |
| 营救任务 | 解救指定数量人员 | 解救5名幸存者 |
| 升级任务 | 提升指定等级 | 船只升级到2级 |

### 目标进度显示
- 实时显示当前进度/目标数量
- 完成的目标显示绿色勾选
- 未完成的目标显示进度条

## 四、任务奖励机制

### 奖励类型

| 奖励类型 | 说明 |
|----------|------|
| 金币 | 游戏主要货币 |
| 经验 | 提升玩家等级 |
| 材料 | 船只升级材料 |
| 补给 | 食物、淡水等航行物资 |
| 道具 | 治疗药水、净化水晶等 |
| 装备 | 武器、护甲等 |
| 海图 | 新海域的探索凭证 |
| 声望 | 提升声望等级 |

### 奖励发放
- 完成任务后自动发放奖励
- 奖励直接进入背包或资源栏
- 可在任务界面查看已获得的奖励

## 五、任务界面设计

### 界面布局
- 顶部：任务分类标签（全部/主线/支线/每日）
- 中部：任务列表卡片
- 底部：任务详情弹窗

### 任务卡片信息
- 任务类型标签（主线/支线/每日）
- 任务名称
- 任务难度（简单/普通/困难）
- 任务描述
- 目标进度
- 奖励预览

### 任务详情弹窗
- 完整任务描述
- 所有目标列表
- 全部奖励列表
- 领取/追踪按钮

## 六、任务追踪系统

### 追踪功能
- 可选择1个任务进行追踪
- 追踪任务显示在游戏界面右侧
- 实时更新任务进度

### 任务提示
- 任务目标完成时弹出提示
- 新任务解锁时弹出提示
- 任务奖励可领取时弹出提示

## 七、任务解锁机制

### 主线任务解锁
- 按顺序解锁，完成前一个解锁下一个
- 部分主线任务有等级要求

### 支线任务解锁
- 根据玩家等级解锁不同难度的支线任务
- 每日刷新，数量与等级相关

### 每日任务解锁
- 玩家等级达到3级后解锁
- 每日任务数量随等级增加

## 八、任务数据存储

### 存储内容
- 已完成任务记录
- 当前任务进度
- 追踪任务状态

### 存储方式
- 本地存储（游客账号）
- 云端存储（微信账号）

## 九、任务与其他系统的关联

### 与海图系统
- 主线任务引导解锁新海图
- 探索任务要求达到指定探索度

### 与航海系统
- 航行任务要求完成指定次数航行
- 战斗任务要求击败指定数量敌人

### 与商店系统
- 部分任务奖励包含商店折扣券
- 任务奖励的金币可在商店消费

### 与角色系统
- 任务奖励的经验提升角色等级
- 部分任务要求角色达到指定等级

## 程序接入说明（v1.25：`08_日常与钓鱼.xlsx`——任务侧）

任务表 68 条 = **daily 12（7001~7012）+ achieve 56（8001~8016 + 8101~8140）**，图鉴/成就是一次性任务，不再有独立表。

| 字段 | 程序语义 |
|---|---|
| `condition_type` | `counter`（累计计数器）/`state`（到达状态判定） |
| `counter_key` | 27 种计数键（kill_*、catch_fish、earn_shell、upgrade_room…），**程序埋点必须与此一一对应** |
| `param_json` | 计数参数（目标 id、区域过滤等） |
| `reward_json` | `shell` / `item` / `equip_random` / `appearance` 四类，可组合 |
| `task_type` | daily 每日 4 点重置；achieve 一次性不重置 |

**经济闸**：daily 单日奖励合计 430 币（程序按 reward_json 求和显示"今日上限"）。行为埋点规范：所有 counter_key 的自增统一走任务管理器单例，禁止散写。

校验：`verify_tasks.py`（68 条 / counter_key 枚举 / reward_json 合法性 / 430 上限）。
