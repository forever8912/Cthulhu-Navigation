## 一、船舱结构

### 1.1 布局

- 船体横剖面分 3 层：**甲板层**（战斗/瞭望）、**船舱层**（生产/功能）、**底舱层**（能源/仓储）
- **动力舱固定在底舱层最深处**——它后来装的东西，最好离人远一点
- **格子制（唯一硬约束）**：每个房间占 `grid_size` 格（生产房 2、战斗房 1、功能房 1），船体等级决定总格数 `grid_total`
  - 船体 Lv1 = **8 格**，Lv2 = 10，Lv3 = 12，Lv4 = 14，Lv5 = 16
  - 建造校验：`已用格数 + grid_size ≤ 当前船体 grid_total`
  - **`max_count` 不是第二个约束，它只是"同类堆叠上限"**（防止 5 门同款炮）。真正的约束永远只有格子——**两者取小**
- 怪物登船后沿"船舷→甲板→舱室"路径入侵，房间即防御节点

#### 战斗房占格与视觉安装层

- `grid_size` 表示建造容量、成本、岗位和系统结算占用，不强制所有设备都画在对应船舱内部。
- `2001`、`2002`、`2003`、`2004` 等实体炮台统一安装在**上甲板炮位**；其逻辑格可映射为甲板下方的弹药、供能、操作或承重空间。
- 炮台操作员在甲板炮位工作，炮口必须越过船舷并具有清晰射界；禁止把完整炮身塞入封闭船舱后隔墙射击。
- UI 选中、建造和换岗仍按原 room/turret ID 与格子结算；表现层通过独立 `deckMountAnchor` 绑定甲板安装点，不改变现有数值配置和存档 ID。

#### 正式朝向、层级与中央交通核

- 正式游戏坐标统一为：船头朝右、航行方向 `+X`、炮口默认朝右。已批准风格定稿只提供气氛与材质参考，其主界面构图需镜像后使用。
- 房间回拼层级从后到前固定为：`hull_back → slot_back → slot_frame → constructed_room → front_sill_occluder`。建造房间必须覆盖所占连续格之间的内部立柱；只有最前沿地槛/栏杆可以遮挡房间。
- 船体中线固定一段不可建造的 `access_core`：包含左右船舱通道、梯子和甲板舱口。它不计入 `build_slot_count`，所有船体等级共用同一逻辑 ID，升级时不得移动。
- 房间分列交通核两侧。稳定槽位按相对交通核的位置命名：左侧由近到远为 `slot_L1/L2/L3...`，右侧为 `slot_R1/R2/R3...`，禁止继续使用会因插入而重排的纯流水号。
- Lv1 的 3 个可视建造格为左侧 `L1+L2`、右侧 `R1`；Lv2 的 6 格为左侧 `L1~L3`、右侧 `R1~R3`。升级只从交通核向船头/船尾外侧追加格位，已有槽位 ID、房间实例、船员岗位和存档引用不得移动或重编号。
- 两格生产房占同侧两个相邻格位；示例中 `1001` 占 `slot_L2+slot_L1`，其内部不保留分隔墙或“假门”，只暴露房间最外侧的左右门。`2001` 逻辑占 `slot_R1`，炮身显示在 `deck_mount_R1`。
- Lv3 的 9 格左右分配尚未冻结；须先完成 Lv2 手机画面验证，再决定 `4+5` 的具体朝向。不得为凑 9 格提前移动交通核。
- 旧 `grid_total=8/10/12...` 配置与新可视格位口径存在冲突，数据迁移前不得直接改存档或运行时数值；由独立配置任务新增 `build_slot_count` 并给出兼容策略。

#### 房门、地板线与船员导航

- 每个一格房模板必须导出 `door_left`、`door_right` 与 `floor_y`；相邻房间只在两侧门锚点与地板线一致时建立通路。
- 两格及以上合并房间隐藏内部格子立柱和内部门，只保留最左、最右外门。房间容量由槽位占用决定，导航不得依赖画面中是否“看起来有空隙”。
- `access_core` 必须导出 `corridor_left`、`corridor_right`、`ladder_bottom`、`deck_exit` 四个锚点；默认船员上下甲板只能经过该交通核。
- 船员路径图由“房间左右门边 + 交通核梯子边”组成。房间损毁可停用生产，但除非明确配置为坍塌，不得自动切断全船通路，避免出现无解困人状态。
- 房间前景必须保留连续站立/行走带。大型设备压到后墙与上半区，船员显示在设备前；低矮控制台可以遮挡身体下部，但不得占满门到门的通行带。
- 当前美术锚点基准：房间规范画布 `900×400`、`floor_y=338`；中央交通核规范画布 `240×400`，左右通道使用同一 `floor_y=338`。运行时允许等比缩放，禁止分别拉伸导致门高错位。

> **为什么 5 间生产房占 10 格**：动力舱 2 + 渔 2 + 植 2 + 水 2 + 工坊 2 = 10。船体满级 16 格，**剩 6 格给炮台和功能房**。这是本作最重要的一条空间取舍——玩家永远不可能"什么都建"，他必须决定这艘船是"能打的"还是"能住的"。**能力上限由格子给，不由数值给。**
>
> **v3.6 合并掉发电舱，正好省下 2 格 = 第二门炮的位置。** 原来玩家必须建 2 间动力 + 2 间发电（各 2 格 = 8 格）才够全船耗能，16 格里一半给了能源；现在 2 间动力（4 格）就够，**多出来的 2 格是他第一门额外炮台的预算**。这不是数值补偿，是设计补偿：**能源房不该是这艘船上最占地方的东西。**

### 1.2 建造与升级

| 规则 | 内容 |
|---|---|
| 建造条件 | `unlock_chapter`（章节）**且** `unlock_hull_level`（船体等级），两者同时满足 |
| 等级上限 | **逐房不同**（v1.14 分档）：动力 **5 阶**；渔/植/水/工坊/瞭望/医务/打捞/忏悔 **3 阶**；**炮台 6 阶**；船体 5 阶 |
| MVP 上限 | 炮台的 `mvp_max_level = 5`。**程序读 `min(max_level, mvp_max_level)`**，1.1 把船体扩到 6 级时改一个数字就开 |
| 升级条件 | 每级自己声明 `require_hull_level`（船体等级表第 18 列）。**旧规则「房间 LvN 需船体 LvN」已作废** |
| 每级换名 | 每升一级换一个具体的东西，见 §3 |

> **为什么取消「房间 LvN = 船体 LvN」**：炮台要 6 阶而船体只有 5 级，这条规则当场就撞墙了。改成逐行声明之后，反而能做出更有意思的节奏——**生活线 3 阶全挤在船体 1~3（早熟），魔法炮 3 阶全挤在船体 3（晚熟但起步即成熟）**。规则少一条，节奏多两种。
>
> **为什么生活线砍到 3 阶**：渔/植/水/工坊/瞭望/医务/打捞/忏悔是"活下去"的房，它们的作用在中期就饱和了。给它们 5 阶，等于强迫玩家在 D5 之后继续往"已经不缺的东西"上砸钱。**把 8 间房的时间预算收回来，全部推给炮台和船体——玩家后期的钱应该有明确的去处：打得更狠，或者船更大。**

### 1.3 房间耐久与修理

- 每个房间有独立耐久值，被海中怪攻击时下降
- 耐久归零 = 房间损毁，功能停用；房间内船员自动转为修理状态（消耗木材，技巧越高越快）
- 玩家可拖拽高技巧船员到损毁房间快速修理；修理中船员不参战
- 详细机制见《战斗系统》第五章

### 1.4 岗位机制

- 每个房间有若干岗位格，拖入船员即上岗（**高频操作**）
- **岗位属性效率**：效率 = 船员对应属性 ÷ `require_attr_value`，**达标 100% 为基准，超出线性加成，封顶 200%**；未达标按实际百分比折算，最低 50%
- **战斗房同用此公式**：器械效率 = 操作属性 ÷ 岗位需求属性，200% = 射击间隔减半
- 无人岗位：房间停摆。**动力舱也一样**——**没人在底舱看着它，全船就断电**。这是全船唯一一间"没人管会立刻出事"的房
- **全员参战期间**：所有在岗船员离岗，5 秒集结后上甲板；期间**全部房间产出归零**，战斗结束 3 秒内恢复满效率（《战斗系统》7.1）

### 1.5 全房间属性需求总表（15 间）

| 房间 | `require_attr` | 属性对产出的影响 |
|---|---|---|
| `1001` **动力舱** | **力量** | 力量越高，能源产出越高。**全程力量岗**——从踩踏板到把一缸电鳗按住，都是体力活 |
| `1101` 钓鱼房 | 技巧 | 技巧越高，渔获效率越高 |
| `1102` 种植房 | 智力 | 智力越高，作物/药材产出越高 |
| `1201` 水源房 | 技巧 | 技巧越高，淡水产出越高 |
| `1301` 工坊 | 技巧 | 技巧越高，生产速度越快 |
| `2001` **鱼叉炮**（单体·物理） | **技巧** | 技巧决定射击间隔。**吃炮弹，受护甲减免** |
| `2004` **霰弹炮**（群体·物理） | **技巧** | 同上。**吃炮弹最多（8 发/次）** |
| `2003` **咒镜炮**（单体·魔法） | **智力** | 智力决定射击间隔。**吃魔晶，无视护甲** |
| `2002` **魔晶炮**（群体·魔法） | **智力** | 同上。**吃魔晶，无视护甲** |
| `3101` 瞭望台 | 技巧 | 预警越早 / 射程加成越高 |
| `3102` 医务室 | 智力 | 治疗速度越快 |
| `3103` 打捞房 | 无需岗位 | 自动运行（`auto_pickup`），效率恒 1.0 |
| `3104` 忏悔室 | 精神 | 精神越高，赎罪券周期越短；**300 币直接清不随精神打折** |
| `9001` / `9101` 船体 | 无需岗位 | — |

> **为什么合并后仍然是力量岗，不是智力岗**：很多人第一反应是"养电鳗该用智力"。但船员在这间房里做的事从头到尾只有两件——**蹬，和按住**。看仪表调电压是陆地上的活；在底舱，你面对的是一个会跳的东西，你需要的不是脑子，是**两个人一起上**。
>
> **这也是这条线能一路走到 Lv5 的原因**：它没有升级成"更聪明的机器"，它升级成"更不怕人的牲口"。**岗位属性不变，说明人在这一级的处境没变——还是在出力气。**

| **Lv4** | —— | D4~D5。生活线已无级可升，**钱只往炮台和船体走**。这是"后期不断线"的关键一级 |

> **矩阵要读出来的三件事**：
> ① **船体 Lv3 是全场最重要的一级**——它同时给了魔法炮、打捞房，还让 4 间生活房封顶。玩家的"基建期"在这一级结束，"火力期"从这一级开始。
> ② **物理炮早熟、魔法炮晚熟**：物理炮船体 Lv2 建、Lv2 就能升；魔法炮船体 Lv3 建、**建出来就能连升到 Lv3**。前者是"一点点变强"，后者是"突然拥有一整套"——这对应世界观里"科技先到、魔法后来"的落差。
> ③ **生活线在 Lv3 封顶是有意的**：它的作用已经饱和了，再往上就是纯数字。**把玩家的注意力从"我还能住得多舒服"推到"我还能打得多狠"。**

## 三、命名体系（v3.6 第三次重做：从"搞怪"推到"驯化深渊"）

**一句话规则：每间房都在回答同一个问题——人拿海里的东西干了什么？**

### 3.0 总纲：恐怖在水里，而人正在用它

v3.4 立过一条铁律：**恐怖在水里，船上是人的地方**。方向对，但它只解决了一半——它让船**安全**了，却没让船**有用**。

在克苏鲁世界里，人面对深渊其实有三种反应，不是一种：

| 反应 | 谁在做 | 在本作里的位置 |
|---|---|---|
| ① **逃** | 出海前的所有人 | 开局叙事，一句带过 |
| ② **挡** | 炮台、医务、忏悔 | 战斗层 |
| ③ **用** | 动力、渔、植、水、工坊、打捞、瞭望 | **经营层——玩家 80% 的时长在这里** |

v3.4 只写了 ①②，所以船是"避难所"。但玩家绝大部分时间在经营，他真正在做的事是③——**他把海里的东西抓上来、塞进机器、让它替他干活**。

所以 v3.6 把"避难所"升级成"**作坊**"：

> **这艘船不是人类躲开深渊的地方，是人类剥削深渊的地方。**

这比"温暖"更有生命力，也更好笑——**因为剥削需要理由，而理由总是很荒唐。**

#### 新铁律：判据从"禁词"换成"主语"

v3.4 用的是一张禁词表（禁"溺""深渊""沉没"）。v3.6 改成判主语——因为这次要的「**溺亡水手滚轮**」正撞在旧禁词上，**但它必须保留，它是整条动力线的转折点。**

| 主语 | 保留 | 删掉 |
|---|---|---|
| **人**（在用、在借、在喂、在按住） | ✅ | — |
| **船 / 人（被它同化）** | — | ❌ 船成了海的一部分；人也被这样对待 |

| 名字 | 主语是谁 | 判定 |
|---|---|---|
| 水手滚轮机 | **船员**——他在用一具尸体当仓鼠轮，还挺得意（描述写明"溺亡水手"） | ✅ 保留 |
| 电鳗发电罐 | **船员**——他捞了一缸，养着（描述写明"畸变"） | ✅ 保留 |
| 沉没方舟 | **船**——船成了海的东西 | ❌ 删 |
| 深渊号 | **船**——船被海命名了 | ❌ 删 |
| 解剖剧场 | **医生**——他在拆一具身体 | ❌ 删，但**不是因为是禁词，是因为它在医务室** |

三族禁词按新判据重列：

| 词族 | 例 | 为什么禁 |
|---|---|---|
| **解剖族** | 解剖、截肢、血、尸、切除 | 让玩家想到"身体被拆开"。**海里的东西被拆是玩法，人被拆是恐怖**——禁的是后者 |
| **吞没族** | 深渊、沉没 | 让船变成海的一部分。**「深渊」本身不是禁词，拿它给船命名才是** |
| **献祭族** | 祭、供奉、圣所 | 指向"向神低头"，而这条线的全部意义是**不低头**——**人只借，不献** |

> **「溺」已从禁词表移出**（v3.6）。溺亡水手是被使用的**材料**，不是船的**命运**。这两件事在文案上是两回事，在旧禁词表里被混成了一件。

### 3.1 四问法：写每个名字之前必须先答完

| # | 问题 | 答不出来的后果 |
|---|---|---|
| ① | 它本来是海里的什么？ | 名字会退化成技术名词（"蒸汽推进器"） |
| ② | 人拿它干了什么？ | 玩家感觉不到"我在用它"，只感觉"我在升级" |
| ③ | 代价是什么（它吃什么 / 会不会反）？ | 升级变成纯收益，压力轴消失 |
| ④ | 船员管它叫什么？ | 名字变成策划语，不是船员语 |

**示范（`1001` Lv3「电鳗发电罐」）**：
① 电鳗——礁石缝里捞的，不知道是什么的幼体
② 装进舱里的海水罐，让它一直放电
③ 它要吃鱼。鱼少了，先暗的是灯，然后才是它瘦下来
④ **电鳗发电罐**——船员就这么叫，语气像在说"一缸咸菜"；描述里才写"畸变"两个字

> **凡是四问答不全的一级，就不要给它起新名字。** 说明这一级没有新东西，只有数字——那是数值曲线该解决的事，不是命名该掩盖的事。

### 3.2 借《黑暗料理王》的三件手法（只借手法，不借内容）

| 手法 | 它怎么做的 | 我们怎么用 |
|---|---|---|
| **① 把恐怖降级成物资** | 怪物＝食材，还有品级、产地、处理工序 | 怪物＝**燃料 / 肥料 / 材料 / 牲口**，同样有品级和工序 |
| **② 一本正经地研究怎么用** | 认真写"最佳烹饪方式" | 船员的备注永远是**操作心得**："别靠墙""按住它""两缸轮班" |
| **③ 用最平淡的词称呼最吓人的东西** | "食材""新鲜度" | "**饵**""**水龙头**""**八只手**""**那位**" |

> **第③条是所有笑点的来源**：恐怖靠形容词，好笑靠**名词**。你越是用一个日常名词指代一个不该存在的东西，玩家越好笑——**因为那说明船员已经习惯了。**

### 3.4 三条贯穿全船的伏笔（不写提示，让玩家自己撞上）

> **v3.7 起，这些伏笔不住在名字里了，住在 `level_desc`（第 21 列）里。** 名字负责一眼懂，描述负责把梗讲完。

**① 「借」线——船上一半的设备是跟海里的东西借的，从来没还过**

| 房间 | 名字 | 描述里的原话 |
|---|---|---|
| `3101` 瞭望 Lv2 | 鹰眼瞭望台 | 「换了一只从深海生物身上**借**的眼睛……问起来船员就说"它反正也用不上"。借了没还。」 |
| `3103` 打捞 Lv3 | 八爪打捞机 | 「**跟它借的八只手**，一次捞八样……没人愿意深究它为什么肯帮忙。」 |

> 两间房、两个器官、同一种说法。**船员从不说"挖下来"，只说"借"——因为"借"听起来不用负责。**
> 玩家如果两间都升到顶、都点开描述，会发现船上有两样东西不属于人类，而它们都在替人干活。**这个发现不需要任何提示文本。**

**② 「船底那位」线——为什么 Lv5 的船叫"不沉方舟"**

`1001` 动力 Lv4 ＝ **船底牵引兽**，描述：「没人下去看过它长什么样。只知道它拴在船底往前拖」
`9001` 船体 Lv5 ＝ **不沉方舟**，描述：「名字叫"不沉"——不是因为它沉不了，是**下面那位不让它沉**。一个字都不解释。」

> 玩家把动力舱升到 Lv4、船体升到 Lv5，两条描述会在他脑子里撞一下——**这是全作唯一一个"玩家比船员知道得更多"的时刻。**

**③ 「到顶之后没人解释」——所有满级描述的共同语气**

| 房间 | 满级名 | 描述收尾 |
|---|---|---|
| `1001` 动力 Lv5 | 永动舵轮 | 「它一直没停过……问起就说"好用就行"」 |
| `9001` 船体 Lv5 | 不沉方舟 | 「一个字都不解释」 |
| `9101` 生命号 Lv5 | 生命号·心脏 | 「没人切开看过。它把船开回了家，这就够了」 |

> 到了顶，船员**不再解释，只是陈述**。因为解释需要理解，而理解是危险的。
> **写作规则：Lv1~Lv4 的描述可以有情绪（自嘲、得意、吐槽），满级的描述只能是陈述句。**

### 3.5 每间房的一个"荒唐细节"（玩家真正会讲给朋友听的东西）

**名字只解决"看一眼"，细节才解决"讲给朋友听"。** 一条合格的细节 = **一个具体物件 + 一句船员会说的话 + 一个不该解释的地方**，三样缺一，就会变成设定集里的注水条目。

| 房间 | 荒唐细节 | 它换来了什么 |
|---|---|---|
| `1001` 动力 | 水手滚轮机里那位每天只跑八小时。**没人规定过，是它自己到点就慢下来**——船员说"它也累"，然后给它换了班 | 把怪物当同事，是这艘船最不正常的地方 |
| `1101` 渔 | 自动拖网的饵是上一次的渔获。**船员管这叫"省饵钱"**，没人提这中间的伦理问题 | 实用主义碾过一切 |
| `1102` 植 | 堆肥温室的地里埋着一头。**它烂得越彻底，菜长得越好**。船员的原话是"这土肥" | 温暖但不干净 |
| `1201` 水 | 活体滤水器里那只蚌是打捞上来的，没人知道它是什么。**它吐的水是淡的，于是全船喝它吐的水**——船员叫它"水龙头" | 全作最平淡的一个词，配最不该平淡的东西 |
| `1301` 工坊 | 骨料工坊的锤子是深渊生物的骨头做的。**老师傅说"这木头不震手"** | 手艺人的评价标准永远只有好不好用 |

| `2004` 炮 | 前两级铁砂筒是"往海里泼铁砂的东西"，第三级才有人承认**"终于像个炮了"** | 土法上马的浪漫 |
| `2003` 炮 | **一发一晶**。船员把咒镜炮当工资在算，不是当武器 | 贵的体感比数值更贵 |
| `2002` 炮 | 观星魔镜长得像望远镜，于是被叫成"观星镜"。**Lv6「巨型观星镜」的描述里才有人澄清：不是望远镜** | 全员嘴硬 |
| `3101` 瞭望 | 鹰眼瞭望台的眼睛借了没还。**问起来船员就说"它反正也用不上"** | 无赖也是一种勇气 |

| `3103` 打捞 | 八爪打捞机借的八只手很听话，**但捞上来的东西一半没人认领，一半有人不肯认领** | 海洋的馈赠都带问题 |
| `3104` 忏悔 | 隔板告解室的告解位中间钉了一块隔板。**因为看不见脸，才说得出口** | 清负面特性的仪式感 |
| `9001` 船体 | 从「木筏」到「不沉方舟」，**每一级都是同一批人吹过的牛，而且真的实现了** | 过度乐观是这艘船的引擎 |
| `9101` 生命号 | 砍它它会疼。**所以现在没人砍了，改用剪的**——剪它不疼，这是船员说的 | 全船最温柔的自我欺骗 |

> **反例（已被砍，别写回来）**：「医务室 Lv3 会解剖怪物研究抗性」——它有趣，但它把船变成了海上最恐怖的地方。**有趣的边界是"人还在"。越过去就只剩猎奇。**
>
> **反向约束**：细节里的"它"越是像人（会累、会记仇、会听话），船就越好笑；越是像神（会凝视、会低语、会注视），船就越恐怖。**前者留在船上，后者赶回海里。**

### 3.6 `name` 与 `level_name` 的关系（程序注意）

**`name` 是内部系统名，`level_name` 才是给玩家看的。UI 一律读 `level_name`，不要读 `name`。**

v3.7 之后**15 间房全部不同名**（连 `2001` 的 Lv1 也从"鱼叉炮"变成了"手掷鱼叉"）。举例：

| room | `name`（内部） | `level_name[0]`（Lv1 显示名） |
|---|---|---|
| `1001` | 动力舱 | 四人脚踏机 |
| `1201` | 水源房 | 雨水收集器 |
| `1301` | 工坊 | 木匠工坊 |
| `2003` | 咒镜炮 | 单晶咒镜 |
| `2004` | 霰弹炮 | 铁砂筒 |
| `3102` | 医务室 | 急救医务室 |
| `9001` | 初级船体 | 木筏 |

> **`name` 现在纯粹是"给程序看的分类名"**。这是好事：`room_1001` 永远读作"动力舱"，不会因为玩家升到 Lv5 就让人以为它是"划桨的"。**显示层和逻辑层彻底分开，以后加美术、加本地化都不用动代码。**

### 3.7 分档的数值曲线（为什么 3 阶房不继续长）

| 档位 | 覆盖房间 | 阶数 | 曲线 |
|---|---|---|---|
| **能源档** | 动力舱（唯一） | 5 | CD 3.0→2.4→1.8→1.5→1.2s（−20%/−25%/−17%/−20%），产出 **20/25/33.3/40/50** 每分钟；Lv4/Lv5 主要卖"不容易被打停" |
| **生活档** | 渔 / 植 / 水 / 工坊 / 瞭望 / 医务 / 打捞 / 忏悔 | 3 | Lv1→Lv2 砍 CD 约 38%，Lv2→Lv3 再砍 30% 并**提前获得原 Lv4/Lv5 的行为**（如「熟了就不动了」的 SAN 加成） |
| **火力档** | 4 组炮台 | 6（MVP 5） | atk 每级 +35~40%，CD 每级 −8~15%，**DPS 逐级约 ×1.5**；Lv5→Lv6 是 1.1 的跳跃点 |
| **船体档** | 9001 / 9101 | 5 | 只给格数 / 耐久 / 甲板岗，不直接提产出 |

> **为什么 3 阶房的 Lv3 要"接手"原 Lv4/Lv5 的行为**：它只有 3 级，终点必须值得爬。所以「恒温菜舱」（SAN +10%）、「老师傅的工坊」（帮工 +10%）、「康复病房」（静养 SAN×2）这些**行为级奖励全部下沉到 Lv3**。**行为奖励跟着"名字"走，不跟着"等级序号"走——名字到了，能力就该到。**
>
> ⚠️ 这三条行为仍需落表（见 §附录 B 待办）。

## 四、动力舱（全船总闸·唯一能源房）

能源是全船运转前提：能源不足时按"功能房→战斗房→生产房"顺序断电。

> **v3.6：原「动力舱 `1001`」与「发电舱 `1002`」已合并为一间。**
>
> 原因很直接——查配置表发现两间的产出条目 `500101` 和 `500201` **指向同一个物品 `itm_energy`**，也就是同一池资源。玩家看到的永远是"能源 +30"，但为此要多建一间 2 格的房、多养一个岗位、多记一套名字。**这是纯重复，不是设计。**
>
> 合并后全船只有一间能源房，`max_count = 2`（想建第二间可以，占 4 格），产出曲线重标定为单条。**省下来的 2 格正好是玩家第二门炮的位置。**

| Lv1 | **四人脚踏机** | 1·力量 | 5 | **20.0** | 3.0s | 人力。四个人轮两台踏板，因为没人能连踩十分钟 |
| Lv2 | **水手滚轮机** | 1·力量 | 10 | **25.0** | 2.4s | 从海里捞上来的东西塞进滚轮里跑。**它不累，但会到点慢下来** |
| Lv3 | **电鳗发电罐** | 1·力量 | 15 | **33.3** | 1.8s | 舱里一口海水罐，罐里是一直在放电的幼体。**它吃鱼** |
| Lv4 | **船底牵引兽** | 1·力量 | 20 | **40.0** | 1.5s | 拴在船底推船的大东西。没人下去看过，也没人想下去 |
| Lv5 | **永动舵轮** | 1·力量 | 25 | **50.0** | 1.2s | 没人喂了，它还在转。船员决定不问 |

**升级消耗（币 / 木 / 铁）**：Lv2 = 400 / 40 / 10 ｜ Lv3 = 1,000 / 100 / 40 ｜ Lv4 = 2,500 / 240 / 100 ｜ Lv5 = 4,000 / 520 / 260

> **为什么 Lv1 是 20 而不是 10**（v1.14 是 10）：Lv1 必须能撑住开局。开局耗能 = 渔 4 + 植 3 + 水 3 + 鱼叉炮 8 = **18**。旧值 10 意味着玩家在建完第一门炮的瞬间就断电——**那不是压力，是劝退。**
>
> **为什么中期还是缺**：Lv3 时全船需求约 **40**（2 生产 + 工坊 + 2 炮 + 2 功能），单间 Lv3 只有 33.3。**这时候玩家必须建第二间动力舱**——占 4 格、多一个力量岗。**能源压力没有被取消，只是从"永远缺"变成了"到点才缺"。**

### 4.2 五个阶的代价（一条"越升级越不像人"的线）

```
四人脚踏机（人出力。累，但干净）
  ↓ 让人歇着，让捞上来的东西跑
水手滚轮机（它替人跑。没人问它愿不愿意，因为它已经不会说话了）
  ↓ 滚轮太慢，换成一整缸会放电的
电鳗发电罐（效率高，但要喂。鱼不够就先暗灯）
  ↓ 电鳗太小，换一个推得动整条船的
船底牵引兽（一个台阶，从"用"变成"驯"）
  ↓ 某天起没人喂它了，它还在转
永动舵轮（不解释了）
```

> **这条线是全作"人类如何利用深渊生物"的主轴，其它房间都是它的变奏。**
>
> **Lv4「船底牵引兽」是分界线**：前三级玩家在**用**（用尸体、用电鳗），Lv4 开始是**共处**——你在船上，它在船下，你们有一个共同目标（往前开）。这个关系比"使用"危险得多，也比"使用"温暖得多。
>
> **Lv5「永动舵轮」的描述为什么是"回家"的语气**：描述里那句"它一直没停过"——：家里总有一样东西你不敢碰、不敢问、但一直在那儿。**它不浪漫，它可靠。**（这一级同时是全船 Lv5「只陈述、不解释」的写作规则的一部分，见 §3.4③）

### 4.3 动力舱的代价（v3.8 已落表）

**`consume_json` 新增 `every_sec` 语义：每隔 X 秒扣一次**（与旧"每周期扣一次"并存）。动力舱五阶统一 **1 食物 : 4 能源**：

| 阶 | 能源/分 | 吃食物 | `consume_json` |
|---|---|---|---|
| Lv1 | 20 | 5.0 食/分 | `[{"item_id":"itm_food","count":1,"every_sec":12}]` |
| Lv2 | 25 | 6.25 | `every_sec: 9.6` |
| Lv3 | 33.3 | 8.33 | `every_sec: 7.2` |
| Lv4 | 40 | 10.0 | `every_sec: 6` |
| Lv5 | 50 | 12.5 | `every_sec: 4.8` |

> **为什么是 1:4**：比率恒定，**升动力舱的收益不会被隐藏的食物通胀吃掉**——玩家能精确算出"升一级 = 多吃 25% 的鱼"。食物不足时动力舱**空转不停机但停止产出**（全船进入断电倒计时，按"功能房→战斗房→生产房"顺序掉线）。
>
> **旧方案（全船食物消耗 +20% 系数）作废**：系数装不进 `consume_json`，且玩家看不见。直接吃物品，资源流动全部可见。

### 4.4 资源闭环与存储上限（v3.8 新增，辐射避难所模式）

**消耗三张口**（全部落表）：

| 消耗口 | 节奏 | 数值 | 落点 |
|---|---|---|---|
| 动力舱吃食物 | 每 12~4.8s | 1 食 : 4 能源 | `04/房间等级表.consume_json` |
| 生产房烧能源 | 每 12s（钓鱼/种植/水）、每 6/4/3s（工坊） | 各 5/分，工坊 10/15/20/分 | 同上 |
| 船员生活 | **每 60s 结算一次** | **每人 2 食物 + 1 淡水** | `09`：`life_tick_sec / life_food_per_crew / life_water_per_crew` |

**存储上限（第 22 列 `storage_cap`，同类相加 = 总仓容；到顶停产空转）**：

| 资源 | 存储房 | Lv1 / Lv2 / Lv3（/ Lv4 / Lv5） | 满配仓容 | ≈多少分钟消耗 |
|---|---|---|---|---|
| 能源 | 动力舱 | 100 / 150 / 250 / 350 / 500 | 1,000（×2 间） | ≈20 min |
| 食物 | 钓鱼 + 种植 | 150/250/400 + 100/180/300 | 700 | ≈25 min |

| 炮弹 | 工坊 | 200 / 350 / 500 | 500 | ≈5 min 连续开火 |

> **上限的设计意图**：离线/挂机收益**有顶**（仓满即停），玩家回来要先"腾仓"（消耗或卖出）才能继续吃产出——这是登录钩子，不是惩罚。能源仓故意最小（消耗最猛），炮弹仓按"一场战斗的量"设计。

**达标配置对账**（船体 Lv3 / 船员 10 人 / 动力 Lv3 / 资源房全 Lv3 / 工坊 Lv2）：

| 资源 | 产出/分 | 消耗/分 | 比值 |
|---|---|---|---|
| 能源 | 33.3 | 钓 5 + 植 5 + 水 5 + 工坊 15 = **30** | **1.11** |
| 食物 | 19.4 + 13 = **32.4** | 船员 20 + 动力 8.33 = **28.3** | **1.14** |
| 淡水 | **10.7** | 船员 **10** | **1.07** |

> **三条都压在 1.1 ± 0.05**（`verify_room.py` 断言）。中期（船体 Lv2、船员 6）能源会短暂落到 1.0——**这是故意的**：逼玩家建第二间动力舱（max_count=2），能源压力从"永远缺"变成"到点才缺"。**全员参战期间食物消耗 ×3**，产出归零——动员是有账单的。

## 六、水源房（3 阶）

**同一间房（`1201`）的三个形态，不是三间房。**

| 阶 | 名字 | 岗位 | 产出 | 说明 |
|---|---|---|---|---|
| Lv1 | **雨水收集器** | 1·技巧 | 淡水 5/min | 等天下雨。新手指引第二步建造 |
| Lv2 | **尿液过滤器** | 1·技巧 | 淡水 8/min | 不问了，过滤吧 |
| Lv3 | **活体滤水器** | 1·技巧 | 淡水 **10.7/min** | 打捞上来的，没人知道它是什么。**它喝咸的，吐淡的**——干净水随便喝。**在海上，这是大事** |

> **为什么这条线是全作笑点最密的一条**：它是唯一一条**用"越来越不体面"来表达强度**的升级线。玩家升到尿液过滤器时会笑一下——这两次情绪都发生在**他真的缺水**的时候。做对了，这间房会成为玩家记得住的三间房之一；做错了，就是一个尿梗。**区别在于前两级的水是不是真的不够用。**
>
> **为什么 Lv3 是"一只蚌"而不是"淡化锅"**：淡化锅是技术方案，解决的是问题；**一只蚌解决的是"我们不知道该怎么解决，但我们找到了一个活的东西替我们解决"**。这正是本作经营层的核心手感——**玩家不是在造机器，他是在收编海里的东西。**
>
> **而且它把笑点放在最平淡的地方**：全船喝着不知道是什么的生物吐出来的水，船员给它起名叫"水龙头"。**没有人觉得不对，这就是最好的地方。**

## 七、战斗房（4 组炮台，v1.14 重做）

> **v1.15：船只自带的「舷侧固定炮 ×2」已取消。**
>
> 原因不是数值，是它让"造炮"这件事失去意义——白送两门不用人、不用弹的固定炮，玩家凭什么还要花 2 格 + 1 个人 + 弹药去建 `2001`？**塔防的塔必须是玩家亲手立的。**
>
> **替代方案：`2001` 鱼叉炮的解锁门槛从船体 Lv2 提前到船体 Lv1**（成本不变，300 币 + 铁 20）。它成了玩家的第一座塔，也成了第一章唯一的火力支点。
>
> **代价已确认**（写进《战斗系统》§4）：没有了免费兜底火力，弹药断供就是真的哑火；1 级船海面击杀率从 65% 降到 61%，仍在设计区间内。

### 7.1 四组炮台的分工（这是本作战斗层的第一张决策表）

| | **单体 · 物理** `2001` | **群体 · 物理** `2004` | **单体 · 魔法** `2003` | **群体 · 魔法** `2002` |
|---|---|---|---|---|
| 名字线 | 手掷鱼叉 → **捕鲸炮** | 铁砂筒 → **扫射霰弹炮** | 单晶咒镜 → **专线咒镜** | 单面魔镜 → **观星魔镜** |

| 解锁 | **船体 Lv1** | 船体 Lv2 | 船体 **Lv3** | 船体 **Lv3** |
| 目标数 | 1 | 3（衰减 1.0/0.7/0.4） | 1 | 5（衰减 1.0/0.8/0.6/0.4/0.2） |

| Lv1 单门 DPS | 9.5 | 9.8（对 3 目标） | **12.5** | 15.0（对 5 目标） |

| 一句话 | **性价比之王**，什么都打，但被重甲吃掉 | **弹药黑洞**，贴脸清场最划算 | **重甲杀手**，贵得要死 | **远程压制**，清场慢但稳 |

> **⚠️ 表里的 `atk` 就是最终单发伤害。** 四门炮的技能（`5001`/`5006`/`5005`/`5002`）`power_ratio` 一律 **1.0**。v1.13 及以前 `atk × 3.0` 与 `atk = 已含倍率的单发` 两套口径并存，导致 D1 火力被放大到《战斗系统》标定值的 **3 倍**——**这条口径差已经修掉，以后不要在任何一层再乘一次技能系数**。倍率差异现在只由两件事表达：**目标数**（1 / 3 / 1 / 5）和 **护甲穿透**（受减免 / 无视）。

> **这四条线是这样互相咬住的**：
> - 单体物理最便宜，但**打重甲精英时 DPS 掉得最狠**——你迟早要买魔法炮。
> - 单体魔法单发最高且无视护甲，但**一发一颗魔晶**——魔晶同时是法器/圣典的锻造料，你迟早会心疼。
> - 群体物理的**单颗弹药效率最高**（2.1 倍 × 8 发 vs 单体 1.0 倍 × 5 发），但射程只有 65~72，**怪必须贴上来**。它是"防线被压到甲板时"的最后一张牌。
> - 群体魔法射程最远、目标最多、无视护甲，但**单只时只吃 1.0 倍**——它只在"真的来了一群"的时候值钱。
>
> **玩家最终会建 2~3 门炮**（16 格只剩 6 格给炮台和功能房；合并能源房多出来的 2 格，通常会变成第三门炮）。所以这不是"选一门好炮"，是**"这一周我打算被哪种怪打死"**。

### 7.6 弹药与魔晶约束

**这是本作唯一的两种"消耗型资源"，也是塔防的核心决策接口。**

| 火力来源 | 单次消耗 | 间隔 | 每分钟消耗 | 说明 |
|---|---|---|---|---|
| `2001` 鱼叉炮 | **炮弹 5** | 4.0s | 75/门 | 单体，性价比最高 |
| `2004` 霰弹炮 | **炮弹 8** | 4.5s | **107/门** | 群体，弹药黑洞 |
| `2003` 咒镜炮 | **魔晶 1** | 3.6s | **16.7/门** | 单体，魔晶同样用于锻造 |
| `2002` 魔晶炮 | **魔晶 1** | 6.0s | 10/门 | 群体，最省魔晶但清场慢 |
| 火枪（枪械类武器） | 炮弹 1 | 1.2s（白装） | 50/人 | 单体，高射速 |
| 近战 / 法器 / 圣典 | **0** | — | 0 | 不需弹药（法器吃魔晶，1.1 起） |

**规则**
- **耗尽 → 该炮台哑火**（不是全船哑火），其他炮台与船员不受影响。**v1.15 起没有"免费兜底火力"了**，所以断弹的后果是玩家看得见的
- 弹药/魔晶**只影响火力，不影响生存**
- 弹药堆叠上限 **500 发**；魔晶堆叠上限 999
- 两者都不在压力轴内（压力轴仍是能源/食物/淡水/SAN 四条）

> **为什么把消耗拆成两种**：如果四种炮都吃弹药，它们就只是"同一种炮的四个数值档"。拆成弹药/魔晶之后，玩家必须同时管两条产线——**工坊产弹药，岛屿和奇遇出魔晶**——而魔晶还是法器/圣典的锻造料。**物理炮和魔法炮的取舍，从"哪门伤害高"变成了"我这一周的资源长什么样"。**

### 7.7 属性绑定规则

- 科技系器械（`2001`/`2004`）：操作员【技巧】决定**房间效率（射击间隔）**
- 魔法系器械（`2003`/`2002`）：操作员【智力】决定房间效率
- 以上效率均为 **50%~200%**，公式见 §A.4
- 单发伤害 = `atk × 技能 power_ratio × 岗位效率`；**物理炮在此基础上再过一次护甲减免，魔法炮不过**

### 8.1 工坊（3 阶，MVP 核心）

**定位：把"资源"转成"火力"的唯一房间。** 它同时是弹药产地和装备产地，两者抢同一条产线——**这是本作最重要的产能取舍**。

| 等级 | 名字 | 弹药产出 | 装备锻造上限 | 升到本级 |
|---|---|---|---|---|
| Lv1 | **木匠工坊** | 40 发/分钟（周期 15.0s） | 破损~精良（白/绿） | 建造：币 250 + 木 30 + 铁 15 |
| Lv2 | **骨料工坊** | 68 发/分钟（周期 8.8s） | 卓越（蓝）+ 材料精炼 +50% | 币 1,200 + 木 50 + 铁 30 |
| Lv3 | **老师傅的工坊** | 100 发/分钟（周期 6.0s） | 完美（紫）+ **可指定 1 条词条族** | 币 4,000 + 木 140 + 铁 90 + 稀有房间图纸 |

**Lv3「老师傅的工坊」的三项终局奖励**
- **夜间加成**：游戏内 20:00~06:00 产量 +20%
- **学徒出师**：可指派 1 名船员做「帮工」，帮工所在房间效率 +10%（全船限 1 人）
- **指定词条**：主动锻造时可指定 1 条词条族（不用扳手奇物也能）
- ⚠️ 帮工 +10% 尚未落表

> **✅ v3.8 已落表**：`1301` 产出组改为 `5017`（炮弹 ×10/周期），CD 15/8.8/6s = **40/68/100 发/分**（对齐《03》§8.1 口径）；`consume_json` = 每 6/4/3s 烧 1 能源。**精铁不再由工坊挂机产出**——高级材料改走事件掉落 + 锻造合成（`06` 配方 5~8），工坊是全船唯一的"能源 → 炮弹"转换器。
>
> **为什么工坊只要 3 阶**：它是"弹药产地"，产率只要压得住需求就够了（需求 36 发/分钟，Lv1 就给 40）。给它 5 阶等于让玩家在"已经不缺弹药"之后继续砸钱。**Lv3 的奖励全部是"质"的（帮工、指定词条、夜间加成），不是"量"的——这正好是 3 阶房该有的终点形状。**
>
> **✗ 不要把 Lv1 调到 36 发/分钟以下**：低于需求会让玩家怀疑"工坊是不是坏了"，这是最冤的流失理由。

### 8.2 忏悔室（3 阶，服务 + 生产双通道）

**它解决的是同一个问题——"怎么把负面特性弄掉"——但给了两种不同的代价。**

| 通道 | 代价 | 速度 | 限制 | 适合 |
|---|---|---|---|---|
| ① **直接清** | **300 贝壳币/条**（不递增） | **即时** | 必须在船上 | 有钱、在港内、急着推进度 |
| ② **生产赎罪券** | **虚空晶 1 → 券 1** + 一个精神岗 + 一段工期 | Lv1 60s / Lv2 45s / Lv3 30s（÷效率） | 要有虚空晶，且它同时是圣典/法器锻造料 | 没钱、材料有余、想囤着带出海 |

| 等级 | 名字 | 需求精神 | CD | 每周期消耗 | 产出 | 能源/分 | 升到本级 |
|---|---|---|---|---|---|---|---|
| Lv1 | **告解小间** | 8 | 60s | 虚空晶 ×1 | 赎罪券 ×1 | 5 | 建造：币 250 + 木 40 + 铁 25 + **龙骨木 ×2** |
| Lv2 | **隔板告解室** | 14 | 45s | 虚空晶 ×1 | 赎罪券 ×1 | 5 | 币 600 + 木 40 + 铁 20 |
| Lv3 | **烛火告解室** | 20 | 30s | 虚空晶 ×1 | 赎罪券 ×1 | 5 | 币 2,400 + 木 100 + 铁 60 + 稀有房间图纸 |

> **为什么虚空晶不能直接当赎罪券用**：v1.4 时它的 `use_effect` 写着 `{"clear_neg_trait":1}`，等于"捡到就能用"——那让忏悔室完全多余。改成"**虚空晶是原料、赎罪券是产品**"之后，三件事同时立住了：忏悔室有了挂机产出的理由；赎罪券成了可囤可带出海的道具；而"送去锻造还是送去忏悔"变成一个真实取舍。
>
> **一周约 19 次海面奇遇，虚空晶一周大概只有 3 个左右**——刚好覆盖首周 5 条负面特性里的 3 条。**生产能把 1,500 币的清特性开销压到 600 币，但压不到 0。**

### 8.3 打捞房（3 阶，0 岗位）

**它是全船唯一一间"不用人"的房间**——0 岗位、自动运行、离线也捞。

| 阶 | 名字 | CD | 每周期产出 | 定位 |
|---|---|---|---|---|
| Lv1 | **打捞钩** | 60s | 木 4~8 / 币 15~25 / 铁 0.4×1~3 / 石 0.25×1~3 | 一张网一根绳 |
| Lv2 | **拖网打捞架** | 45s | 同上 | 船走，网捞 |
| Lv3 | **八爪打捞机** | 32s | 同上 + **10% 额外稀有材料** | 网下去，总有东西浮上来。**一次捞八样，深水也够得着**——没人愿意深究它为什么肯帮忙 |

- 产出组 `5016`（`03/掉落组表`），模式 `all`
- 建造：**币 250 + 木 40 + 铁 25**（不占人手，**不消耗龙骨木**）
- 升级：币 600 / 币 2,400 + 木 100 + 铁 60

> **为什么它比生产房便宜却比生产房弱**：不占人手就是它全部的卖点。如果产率再追上生产房，玩家会问"那我为什么要养船员"。**0 岗位房的产率上限必须是同类的一半左右，这条不能破。**

## 九、房间 trade-off 总表（设计自检）

| 房间 | 核心矛盾 |
|---|---|
| **动力舱** | 免费但**必须有人一直站在那儿**；越往后越不靠人，越靠"下面那位肯不肯动"。**它是全船唯一的单点故障** |
| **鱼叉炮（单体物理）** | 最便宜、最全能，但**被重甲吃掉一截**——你迟早要买魔法炮 |
| **霰弹炮（群体物理）** | 单颗弹药效率最高，但**射程只有 65~72**，怪得贴上来 |
| **咒镜炮（单体魔法）** | 单发最高、无视护甲，但**一发一颗魔晶**，而魔晶还是锻造料 |
| **魔晶炮（群体魔法）** | 射程最远、目标最多，但**单只时只有 1.2 倍**，只在"真来了一群"时值钱 |
| 钓鱼房 | 稳定但战时罢工；Lv3「许愿」用食物换稀有鱼 |
| 种植房 | 稳定慢产，战时不断供；Lv3 是全船唯一能提 SAN 的房 |
| 水源房 | 用"越来越不体面"表达强度；Lv3 之前水真的不够 |
| **工坊** | **产弹药就产不了装备**——同一条产线，全作最痛的取舍 |
| **瞭望台** | 占 1 格换 25% 全船射程；不打仗的时候它什么都不产 |
| **医务室** | 唯一能救回濒死船员的房；但它也不产任何资源 |
| **打捞房** | 0 岗位换低产率：不占人手、离线也捞，但只有生产房一半 |
| **忏悔室** | **省下的每一张券，都是一件装备的材料** |
| **船体** | 只给格数/耐久/甲板岗，不直接提升产出——**但它是唯一能让你多建一间房的房** |

设计原则：每个房间必须有"要它"和"不要它"的理由，杜绝无脑全建。**而 16 格的上限保证了"无脑全建"在物理上不可能。**

## A.4 属性与计算公式（程序实现口径）

```
岗位效率 = clamp(船员属性 ÷ require_attr_value × (1+装备岗位效率加成), 0.5, 2.0)
  · need_crew=0 的自动房间效率恒 = 1.0

房间等级上限 = min(max_level, mvp_max_level)
房间可升到 LvN 的条件 = 当前船体等级 >= 该行的 require_hull_level
房间可建造的条件 = 章节 >= unlock_chapter 且 船体等级 >= unlock_hull_level

生产房间：
  实际生产周期 = produce_cd ÷ 岗位效率
  每周期：先扣 consume_json（不足则不产出、空转不停机），再对 produce_drop_group_id 跑一次 roll
  每分钟产出期望 = 60 ÷ 实际周期 × 掉落组期望产出

能源平衡：
  产出/分钟 = Σ 能源房 itm_energy 期望产出
  消耗/分钟 = Σ 所有 is_energy=0 且已建房间的 energy_consume
  产出 < 消耗 → 按 "功能房→战斗房→生产房（能源房除外）" 顺序断电

战斗房间：
  实际攻击间隔 = atk_cd ÷ 岗位效率（效率 200% = 射速翻倍）
  单发伤害 = atk × 技能 power_ratio × 岗位效率
  开火前检查 atk_consume_json：不足 → 本炮台哑火（跳过本次攻击，不消耗）
  物理炮（skill 5001/5006）：单发伤害再过一次护甲减免 armor/(armor+60)
  魔法炮（skill 5005/5002）：**跳过护甲减免**
  射程 = atk_range × (1 + 瞭望台加成)

航速：
  船只实际航速 = Σ 所有已建房间（含船体）的 speed

承伤：
  减伤率 = armor ÷ (armor + 60)，上限 60%
  hp 归零 → 房间损毁停用；船体 hp 归零 → 沉没
```

## 程序接入说明（v1.25：`04_房间与生产.xlsx`）

### 数据源与加载顺序

4 sheet：房间表（15 房定义）→ 房间等级表（63 行 = 每房每级一行，**主键 (room_id, level)**）→ 船体等级矩阵 → 初始船只配置表。

### 房间等级表运行时字段

| 字段 | 程序语义 |
|---|---|
| `upgrade_cost_json` | 升到本级的消耗；`bp_*` 蓝图直接作为 item 检查背包（全游戏仅 5 处：1301/3102/3104 Lv3、9001 Lv5、9101 Lv3/Lv5） |
| `consume_json` | 持续消耗。两种键：`every_sec`（每 N 秒扣 1 个，动力舱吃食 1:4、生产房 12s/能源）与生活结算（走 09 参数 life_tick_sec/life_food_per_crew/life_water_per_crew，**不在本表**） |
| `storage_cap` | 本级仓容，**同类资源房相加 = 总仓容**；资源到顶 → 生产暂停（空转不消耗） |
| `produce_drop_group_id` + `produce_cd` + `produce_roll` | 周期产出：每 CD 秒 roll 一次掉落组 |
| `atk` / `atk_cd` / `atk_range` / `atk_consume_json` | 炮台：单发伤害（已是最终值，勿再乘 power_ratio）、射速、射程、开火耗弹 |
| `require_hull_level` | 船体等级门槛（与船体等级矩阵列联动） |
| `level_name` / `level_desc` | 界面文本：名字 + 运作方式描写（≥40 字） |

### 船体等级矩阵

行 = hull_level 1~6（6 为 v1.1 预留行不生效）；列 = 各房间的**本级可建/可升上限**。程序读矩阵决定"当前能造什么"，读房间表 `max_count` 决定"能造几个"。

### 生活结算（走 09，不建表）

每 `life_tick_sec`（60s）：全员扣 `life_food_per_crew`×人数 食物 + `life_water_per_crew`×人数 淡水；缺供 → 依次触发效率惩罚（特性系统接管）。达标对账锚点：能源 1.11 / 食物 1.14 / 淡水 1.07（≈1.1:1，校验断言）。

`verify_room.py`（22 列 / every_sec / cap / 对账 / 名字含核心词 / desc≥40 字）。
