# 《恐惧之海》微信小游戏版 - 钓鱼系统

> 版本：v2.0（新建）  
> 定位：前期日常打发时间的轻玩法，后期并入捕鱼房间自动化；产出食物与特殊材料，承载鱼类图鉴收集。

## 一、玩法形态（MVP即双线并行）

| 形态 | 操作 | 说明 |
|---|---|---|
| **玩家主动钓鱼** | 主角船舷点击抛竿，纯概率结算 | 打发时间的日常玩法，随时可点，无CD限制（有"再抛一竿"广告点位） |
| **船员自动钓鱼** | 安排船员在钓鱼房（捕鱼房）上岗自动作业 | 每隔一段时间结算一批鱼获，弹窗展示收获 |

- 主动钓鱼：点击船舷水面 → 抛竿动画 → 3-5s后结算结果（纯概率：空军/普通鱼/稀有鱼/异物）
- 自动捕鱼：房间内船员上岗后按效率产出，**每隔一段时间（如30min）弹出收获结算**，展示本批鱼获清单（可一键领取）
- 1.1鱼叉炮房：可对海中怪开火的同时捕鱼，但招怪

## 二、概率结构（基准值）

| 结果 | 权重 | 说明 |
|---|---|---|
| 空军 | 25% | 空手而归（manual only，自动捕鱼无空军） |
| 普通鱼 | 55% | 白色/绿色品质 |
| 稀有鱼 | 15% | 蓝色/紫色品质 |
| 特殊鱼 | 4% | 紫色/橙色品质，制作材料 |
| 异物 | 1% | 怪物/垃圾/剧情物品 |

- 海域影响：不同海域栖息不同鱼种，深海海域稀有度权重上移
- 钓鱼房岗位【技巧】属性：提高稀有/特殊鱼权重（技巧每10点+2%稀有权重）

## 三、鱼类图鉴

**第一版图鉴总数：40种鱼**（按海域分布，每海域约12-15种，含特殊鱼）。

每条鱼记录：

| 字段 | 说明 |
|---|---|
| 名称/立绘 | AI生图素材 |
| 稀有度 | 白/绿/蓝/紫/橙 |
| 栖息地 | 出现海域（图鉴按海域分页） |
| 累计捕获数 | 账号级统计 |
| 最大尺寸 | 每次捕获roll尺寸，刷新纪录（收藏钩子） |
| 用途 | 食物转换 / 制作材料 / 任务道具 |

### 图鉴成就奖励（复用任务系统）
- 图鉴成就=一次性任务，完成后奖励**游戏币**（游戏币用途见《日常与留存系统》）
- 每海域集齐普通鱼种 → 游戏币奖励
- 集齐该海域全部鱼种（含特殊） → 游戏币+特性卷轴/转职书碎片
- 尺寸纪录：单鱼种破纪录时小奖励（游戏币/食物）

## 四、鱼类用途

| 鱼类型 | 用途 |
|---|---|
| 普通鱼（白/绿） | **转换为食物**（自动或手动一键转换） |
| 稀有鱼（蓝/紫） | 高价值食物；部分为转职任务材料（如"船员→渔夫"需钓上X条蓝色品质鱼） |
| 特殊鱼（紫/橙） | **制作材料**：工坊高级配方（如鱼油=精神经验道具、硬骨=锻造辅料、发光鱼=魔晶合成） |

### 特殊鱼示例
| 鱼 | 稀有度 | 用途 |
|---|---|---|
| 深渊灯笼鱼 | 紫 | 魔晶合成材料 |
| 铁骨鳕鱼 | 蓝 | 锻造辅料（锻造优质率+5%） |
| 梦鳞鱼 | 橙 | 忏悔室清除消耗-50%一次性道具 |
| 腐肉鱼 | 绿 | 可喂食怪物（驱散一次袭击） |

## 五、与其他系统联动

| 系统 | 联动 |
|---|---|
| 船舱房间 | 钓鱼房（技巧岗）/鱼叉炮房（技巧岗+招怪）为自动捕鱼载体 |
| 船员养成 | 钓鱼产出转职任务材料（渔夫线）；鱼类道具给属性经验 |

| 商业化 | 广告点位候选："再抛一竿"（手动钓鱼立即重置CD） |

## 程序接入说明（v1.25：`08_日常与钓鱼.xlsx`——钓鱼侧）

5 sheet：鱼类表 → 钓鱼概率配置表 → 钓鱼掉落组表/条目表（与 03 同构算法）→ 鱼类道具关联表。

- **钓鱼概率配置表**：按 (zone_id, result_type) 权重抽结果；`tech_bonus_per_10` = 技巧每 10 点对权重加成比例
- **鱼类表**：`size_min~max` 随机尺寸（入图鉴/卖价系数）；`food_value` + `use_type`（直接食用/转换为道具）
- **鱼类道具关联表**：鱼 → 食物换算（`convert_food_count`，`convert_cost` 手续）
- 持续消耗：钓鱼房每 12s 耗 1 能源（04 consume_json）；任务计数器 `counter_key` 见任务系统侧
- 校验：`verify_tasks.py`（含钓鱼掉落引用）
