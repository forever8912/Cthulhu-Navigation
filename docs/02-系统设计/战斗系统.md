> 版本：v2.4（**按塔防重设战场距离与射程带**；新增第 2 个主动技能「全员参战」；战败不致死；传送逃跑；四类主武器：近战/枪械/法器/圣典）  
> v2.3：战败不致死、取消战前准备；v2.1 补齐战斗数值公式；v2.0 挂机塔防框架不变  
> 横版挂机塔防：怪物自海面游来→攀上船舷→入侵舱室。船员全自动战斗，玩家高频操作是**拖拽船员调岗**，低频操作是**全员参战 / 传送逃跑**两个主动技能。
>
> **v2.4 核心变更**：怪物从出现到登船有一条可测量的"路程"，远程单位在怪物进射程后就开始输出，近战必须等它贴舷。战斗数值不再按"队伍DPS×TTK"平铺，而是按**每段路程能给多少输出窗口**反推（口径见《怪物系统》第一章）。

## 一、战斗基本结构

### 1.1 战场
- 战场=船体横剖面+左右两侧海面延伸区
- 怪物行进路径：**海面（游弋接近）→ 船舷（攀爬）→ 甲板（交战）→ 舱室（入侵）**
- 房间即防御节点：怪物入侵房间后，房间内船员就地参战，房间产出停止

### 1.2 战斗触发
| 触发 | 说明 |
|---|---|
| 航行袭击 | 航行中随机刷怪来袭（瞭望台可提前10s预警方向） |
| 鱼叉炮·捕鱼模式招怪（1.1） | 该模式工作时袭击频率+30% |
| 宝箱出怪 | 漂浮物宝箱概率开出怪物 |
| 钓鱼异物 | 钓鱼房Lv3小概率钓上小怪 |
| Boss战 | 海域终点节点，玩家主动发起（需SAN抗性达标） |

### 1.3 战场距离与射程带（**塔防核心 · SSOT**）

> 本节是"谁能打到谁"的唯一事实来源。程序用 `progress`（0~100）表示怪物在路径上的位置；所有射程判定只读本节，其他文档不重复定义。

**距离刻度**：`100 = 怪物出现线（远海）` → `20 = 接触船舷（开始攀爬）` → `0 = 甲板`

| 距离带 | 区间 | 可攻击的单位 |
|---|---|---|
| 远海 | 100~65 | 炮位 |
| 近海 | 65~55 | 炮位、枪械 |
| 舷外 | 55~20 | 炮位、枪械、法器 |
| 攀爬 | 20~0 | 全部远程 + 贴舷近战 |
| 甲板 | 0 | 全部单位（含近战） |

**射程值表**（配表字段 `range`）

| 单位 / 武器 | range | 首次可攻击距离 | 海面阶段输出窗口* |
|---|---|---|---|
| 炮位 / **火炮房 Lv1~Lv3**（器械） | 95 | 95 | 94% |
| 枪械 | 65 | 65 | 56% |
| 圣典（治疗射程） | 60 | — | — |
| 法器 | 55 | 55 | 44% |
| 近战 | 20 | 20（攀爬开始） | 0% |

\* 输出窗口 = 该单位可打的海面距离 ÷ 全程海面距离（80）。按普通怪 9s/80 距离折算，炮位 8.4s、枪械 5.1s、法器 3.9s。

**三条硬规则**
1. **远程是主力，近战是兜底**：远程在怪物刚出现就开始输出，近战要等它贴舷。队伍总输出的 **70~75% 来自远程**，近战负责清漏网怪与护甲单位。
2. **射程补偿**：近战基础伤害配置比枪械高约 **30%**（射程换伤害），但总输出仍低于远程——否则远程的射程优势失去意义。
3. **瞭望台只加射程不加伤害**：全船射程 +10%（枪械 65→71.5、法器 55→60.5、炮位 95→100 封顶），等于把"能打的时间"拉长 10%。这是瞭望台唯一的价值来源，不要再给它伤害加成。

> **反直觉但必须保留**：怪物在海面时，近战船员是"哑火"的。这不是数值缺陷，而是塔防的节奏设计——怪物还在路上时只有远程在打，玩家能清楚看到"防线能不能顶住"，而近战接战的那一刻就是"漏怪了"的视觉信号。

## 二、船员战斗规则

### 2.1 全自动战斗
- 器械（炮位）：自动索敌开火，吃弹药/魔晶
  - **操作员属性只影响房间效率（射击间隔），单发伤害由器械与炮弹决定**
  - 科技炮位：操作员【技巧】；魔法炮位：操作员【智力】
  - 与生产房共用“属性÷需求→效率”模型：装备/词缀的岗位效率加成参与封顶前计算，最终有效效率仍≤200%
- 非器械战斗船员：持装备武器，自动攻击/治疗射程内目标。武器分四类，**主属性与效率属性必须不同**（定义见《角色系统》2.1）：
  - 近战：【力量】决定伤害发挥率，【技巧】决定攻击间隔
  - 枪械：【技巧】决定伤害发挥率，【智力】决定释放间隔（效率属性）
  - 法器：【智力】决定伤害发挥率，【技巧】决定释放间隔
  - 圣典：【精神】决定治疗发挥率，【技巧】决定释放间隔；对非亡灵只治疗，对亡灵才结算伤害（见 3.9）
  - 伤害轴与效率轴各自 50%~200%；效率属性由武器配置，同一属性不得同时决定某类武器的强度与间隔
  - 平A与主动技能共用一个出手队列：主动CD好了替换下一次平A（见《技能系统》4.1）
- 射程规则：见 §1.3 射程带。瞭望台提供全船射程 +10%（只拉长输出窗口，不加伤害）

### 2.2 站位
- 甲板船员默认就近迎战船舷侧的敌人（远程站在甲板内侧，近战站在舷边）
- **舱室内船员默认不参战**：生产/功能房船员在战斗中继续工作（种植房照产、医务室照治），只有怪物入侵该房间时才就地接战
- 想让生产岗也上甲板 → 用主动技能「全员参战」（见 §7.1），代价是生产停摆 + 食物加速消耗
- 拖拽即调岗：战斗中可随时把船员拖向甲板增援，或把濒死船员拖入医务室（脱战）

### 2.3 属性、效率与SAN
- 伤害轴与效率轴分离，各自 **50%~200%**，详见第三章
- **SAN战斗修正为独立乘区**：高昂×1.10 / 正常×1.00 / 低落×0.85 / 崩溃×0.70；崩溃另有概率离岗
- SAN修正作用于最终伤害（等效DPS），不再重复作用于攻速，避免双重惩罚
- 全员崩溃是 Boss 战失败的主因——SAN 管理是跨场次的核心备战动作（不设战前准备阶段，靠战前若干场的资源与图鉴积累）

## 三、战斗数值公式

### 3.1 总公式

```
基础伤害 B = 主属性 × K + 武器伤害 × 武器发挥率 + 固定附加伤害

百分比修正 P = clamp(1 + 攻方增伤率 - 守方减伤率, 0.40, 2.00)

暴击修正 C = 暴击判定成功 ? 暴击倍率 : 1.00

格挡修正 G = 格挡判定成功
            ? max(B × P × C - 格挡值, B × P × C × 10%)
            : B × P × C

最终伤害 = max(1, round(G)) + 真实伤害

期望DPS = 期望单次伤害 × 每秒攻击次数 × SAN修正
```

- K = 1.0（MVP基准系数，可调；用于控制“属性平A项”与“武器伤害”的占比）
- 武器发挥率 = clamp(角色主属性 ÷ 武器属性需求, 50%, 200%)
- 真实伤害不参与百分比修正、暴击与格挡，最后独立相加
- 取整方式全项目统一（建议四舍五入），最终伤害最低1点
- 期望暴击修正 = 1 + 暴击率 × (暴击倍率 - 1)；数值验收用期望DPS，单次结算用实际判定

> 与初版公式的差异（修正理由）
> 1. 初版把真实伤害放在括号内，会被增伤/减伤系数缩放，语义矛盾 → 移到末尾独立相加。
> 2. 初版把格挡固定减伤放在百分比修正之前，实际减伤量会被系数缩放，不再是“固定值” → 移到百分比与暴击之后。
> 3. 初版未限制(1+增伤-减伤)的区间，可能出现0伤害或负伤害 → 限制在0.40~2.00。
> 4. 初版“暴击伤害值”未定义 → 明确为倍率，基础150%。
> 5. 初版未定义主属性系数、取整与最低伤害 → 本版补齐。

### 3.2 各项定义与来源

**武器类别结算差异（定义 SSOT 见《角色系统》2.1）**

| 武器类别 | 主属性（决定发挥率） | 效率属性（决定释放间隔） | 结算类型 |
|---|---|---|---|
| 近战 | 力量 | 技巧 | 物理伤害 |
| 枪械 | 技巧 | 智力 | 物理伤害（远程） |
| 法器 | 智力 | 技巧 | 魔法伤害 |
| 圣典 | 精神 | 技巧 | 治疗 / 对亡灵魔法伤害 |

| 项 | 定义/公式 | 来源 | 上下限 |
|---|---|---|---|
| 主属性 | 近战=力量；枪械=技巧；法器=智力；圣典=精神 | 船员面板 | — |
| 属性系数K | 主属性转固定伤害的系数 | 全局配置 | MVP=1.0 |
| 武器伤害 | 武器/器械面板基础伤害（圣典此项为0） | 武器/器械 | — |
| 武器发挥率 | clamp(主属性 ÷ 主属性需求, 50%, 200%) | — | 50%~200% |
| **释放效率** | clamp(效率属性 ÷ 效率需求, 50%, 200%)，效率属性由武器配置 | 船员面板+武器 | 50%~200% |
| **治疗量** | (主属性 × K + 圣典治疗值 × 发挥率) × (1+治疗加成)，与伤害同构 | 船员面板+圣典 | 单次 ≤ 目标HP上限×30% |
| **治疗间隔** | 圣典基础间隔 ÷ 释放效率 ÷ (1+攻速修正) | 圣典+船员 | 同效率轴 |
| 固定附加伤害 | 不随属性缩放的固定加值 | 技能/词缀 | MVP=0 |
| 攻方增伤率 | 词缀/技能/对精英Boss加成相加 | 装备/技能 | ≤100% |
| 守方减伤率 | 护甲/魔抗转换+词缀+技能相加 | 装备/技能 | ≤60% |
| 暴击率 | 基础5% + 技巧×0.2% + 加成（属性来源 ≤+20%） | 全局/技能 | ≤50% |
| 暴击倍率 | 基础150% + 加成 | 全局/技能 | ≤300% |
| 格挡率 | 基础0% + 加成 | 技能/装备 | ≤50% |
| 格挡值 | 格挡成功时的固定减伤数值 | 技能/装备 | 建议5~50 |
| 真实伤害 | 无视P/C/G的固定伤害 | 1.1+技能/橙装 | MVP=0 |
| 攻速修正 | 词缀/技能直接给的攻速% | 装备/技能 | ±50% |
| SAN修正 | 高昂1.10/正常1.00/低落0.85/崩溃0.70 | SAN系统 | 独立乘区 |

> 四维中无独立“魔法”属性：法器主属性取【智力】；【精神】自 v3.1 起通过圣典进入输出侧（治疗/对亡灵伤害），同时保留防御侧（魔抗/SAN）。武器类别与主属性分工的唯一事实来源是《角色系统》2.1。

### 3.3 攻速/射击间隔（房间效率统一模型）

```
效率 E = clamp(操作属性 ÷ 需求属性, 50%, 200%)
实际间隔 = 基础间隔 ÷ E ÷ (1 + 攻速修正)
每秒攻击次数 = 1 ÷ 实际间隔
```

- **器械（炮位）**：操作属性=技巧（科技）/智力（魔法）；需求属性=房间岗位需求；单发伤害由器械与炮弹决定，不吃操作员属性
  - 例：火炮基础间隔10s，需求技巧5；操作员技巧10 → 效率200% → 间隔5s；技巧2 → 效率40%→按50%下限 → 间隔20s
  - 效率200%后继续堆同一属性不再提升该炮位射速；需升级炮位提高需求，或换更高阶器械
- **船员武器**：统一走一条释放效率公式，效率属性由武器配置（表见 3.2）
  - `释放效率 = clamp(效率属性 ÷ 效率需求, 50%, 200%)`
  - `实际间隔 = 基础间隔 ÷ 释放效率 ÷ (1 + 攻速修正)`
  - 当前配置：枪械=智力；近战/法器/圣典=技巧。新增武器可换用其他属性，公式不变
  - 武器表配置“主属性需求”与“效率需求”；MVP 可让两者相等，后续按类别分化（重武器效率需求高、轻武器低）
  - 圣典走同一间隔公式，只是间隔结算的是治疗而非攻击（见 3.9）
- **语义统一**：效率200% = 间隔减半 = 攻速翻倍；效率50% = 间隔×2。不要写成“攻速+200%”
- 装备/词缀的“岗位效率+X%”（如老水手的）乘在属性效率之后、封顶之前：
  - 有效效率 = clamp(属性效率 × (1 + 岗位效率加成), 50%, 200%)
  - 它只能帮助未达标船员更快接近上限，不能突破200%；岗位效率加成建议总上限+25%
- 攻速修正来自装备词缀（之迅捷+10%、沉重-8%），作为独立乘区，不与技巧效率混算

### 3.4 判定顺序与硬上限

**结算顺序（必须按此顺序）：**
1. **命中判定**（MVP默认必中；仅当存在闪避/命中惩罚时判定）
2. 计算基础伤害B
3. 乘百分比修正P
4. 暴击判定，成功则乘暴击倍率C
5. 格挡判定，成功则减格挡值G（最低保留10%）
6. 加真实伤害
7. 取整，最终伤害最低1点

> 治疗与以上结算分离：不走命中/暴击/格挡，也不吃守方减伤率，只结算治疗量与治疗间隔（见 3.9）。

**硬上限速查：**

| 项 | 范围 |
|---|---|
| 武器发挥率 | 50%~200% |
| 器械房间效率（操作属性÷岗位需求） | 50%~200% |
| 释放效率（武器，效率属性由武器配置） | 50%~200% |
| 单次治疗量 | ≤ 目标HP上限×30% |
| 治疗加成（词缀/技能） | 0%~+50% |
| 岗位效率加成（装备/词缀） | 0%~+25% |
| 攻方增伤率 | 0%~100% |
| 守方减伤率 | 0%~60% |
| 百分比修正P | 0.40~2.00 |
| 暴击率 / 暴击倍率 | ≤50% / ≤300% |
| 格挡率 / 格挡后最低保留 | ≤50% / 10% |
| 攻速修正 | -50%~+50% |
| 命中率（启用时） | 60%~100% |
| 最终伤害 | ≥1 |

- **命中与闪避**：MVP默认必中，避免挂机MISS造成DPS方差；迷雾/墨水/致盲等技能施加“命中惩罚”时才启用判定
  - 命中率 = clamp(100% + 攻方命中加成 - 守方闪避 - 命中惩罚, 60%, 100%)
- **百分比减伤 vs 格挡**：百分比减伤走“减伤率”；格挡只走“固定值”。怪物技能若写“减少50%伤害”，实现为临时减伤率+50%，不强行转成格挡

### 3.5 防御转换（护甲/魔抗/意志）

```
物理减伤率 = 护甲 ÷ (护甲 + 60)，上限60%
魔法减伤率 = 魔抗 ÷ (魔抗 + 60)，上限60%
怪物魔抗默认 = 护甲 × 0.6（可在怪物表单独覆盖）
船员魔抗 = 精神 × 1 + 智力 × 0.3 + 装备/特性魔抗（来源见《角色系统》第五章）
船员减伤率 = 装备/词缀/技能直接提供的减伤率%相加，上限60%
SAN抵抗 = 精神 ÷ (精神 + 60)，只减免恐惧伤害，不并入减伤率乘区
```

| 护甲 | 物理减伤率 | 护甲 | 物理减伤率 |
|---|---|---|---|
| 3 | 4.8% | 20 | 25.0% |
| 5 | 7.7% | 25 | 29.4% |
| 8 | 11.8% | 30 | 33.3% |
| 10 | 14.3% | 35 | 36.8% |
| 12 | 16.7% | 40 | 40.0% |
| 15 | 20.0% | 45 | 42.9% |

> 魔法对高护甲目标更有效：护甲45的怪物魔抗=27，魔法减伤率仅31.0%。

### 3.6 数值示例

> 以下均按K=1.0、未计暴击（暴击期望另加约2.5%），目标减伤按3.5公式。

| 场景 | 参数 | 计算 | 结果 |
|---|---|---|---|
| 器械·达标 | 单发25，需求技巧5，操作技巧10，目标护甲3 | 效率=200%→间隔5s；减伤4.8% | 24/发，4.8 DPS |

### 3.7 合理性自检与调参锚点

**1. 双轴封顶的倍率区间**
- 伤害轴0.5~2.0，攻速轴0.5~2.0 → 最差/最好的人岗匹配，DPS相差 **16倍**（0.25x~4x）
- 这是“人事调度”核心玩法的强度来源，但16倍偏陡；上线前用两条保险：
  - 岗位需求按新手阶段配置得低（例：炮位Lv1需求5），新手很难掉到50%下限
  - 角色/装备界面必须显示“发挥率、技巧效率、预估DPS”，让玩家看见换人/换装的变化
- 若实测仍偏陡，优先把双轴下限从50%提到70%（差距收敛到约8倍），不要先砍200%上限

**2. 主属性平A项（K）的作用**
- 发挥率封顶后，属性仍通过K项线性提升伤害，避免“属性达标后继续养成无收益”
- 代价是后期武器基础伤害占比下降；调参顺序：先提高武器强化/基础伤害，再考虑下调K

**3. 高稀有度武器可能暂时更弱**
- 高稀有度武器需求更高，属性未达标时DPS可能低于低稀有度武器
- 这不是bug，是“熟练度门槛”；必须用装备界面提示，且需求值按投放阶段配置（到手时属性≈需求的1.5~2.0倍）

**4. 数值锚点（塔防口径，v2.4 重设）**

> 旧口径"队伍总 DPS 60 × TTK 秒"已作废——它把海面路程当成了纯等待时间，忽略了"远程已经在打、近战还在哑火"这件事。新口径按**输出窗口**反推（完整推导见《怪物系统》1.1~1.3）。

**队伍基准（MVP 海域1、白装、属性恰好等于需求）**

| 单位 | 单件 DPS | 数量 | 小计 | 耗弹 |
|---|---|---|---|---|
| 远程甲板船员·火枪（白装：发挥率100%、间隔1.2s、单发14） | 11.7 | 3 | 35.1 | **1 发/次** |
| **远程合计 D_r（船体 Lv1，无炮台）** | | | **≈35** | — |
| `2001` 鱼叉炮 Lv1 ×1~2（单发38/间隔4.0s＝**9.5/门**，单体，再乘弹药覆盖率 0.75 → 7.1/门） | 7.1 | 0~2 | 0~14.2 | **5 发/次** |

| 近战甲板船员（登船后才开打） | 15.2 | 0~1 | 0~15 | 0 |

- **远程 D_r ≈ 35（无炮台）/ 42（1 门）/ 49（2 门）**。**锚点取 42 = 1 门炮的中位状态**，这是所有普通怪 HP 的反推基准；近战不参与海面窗口计算，只参与"登船后清场"，因此单列
- **v1.15：舷侧固定炮 ×2 已删**。它原来贡献 10 DPS（两门舷炮），是 D_r 从 45 起算的一部分。删掉之后，**第一座塔改由玩家自己造**——`2001` 鱼叉炮解锁门槛从船体 Lv2 提前到 **船体 Lv1**。旧口径 45 与新口径 42 相差 7%，**在怪物 HP 的容差内，表不重算**
- 数值锚点：普通怪 HP ≈ `42 × 9 ÷ (4只 × 0.65)` ≈ **145**，**表内仍沿用 155**（旧口径 45 反推值，偏高 7% 属安全余量）；精英 = 总DPS 56 × 11s ≈ **620**（表内 660）；Boss = 56 × 45s ≈ **2520**（表内 2700）。**三条都保留了 5~7% 的余量，方向一致（怪略硬），不需要动表**｜舷炮删除后 1 级船的实际海面击杀率由 65% 降到 **61%**，仍在 60~70% 区间内
- **炮台把 D_r 从 35 提到 49（+40%），但怪物 HP 表本次不做重算**。理由与风险：
  ① 炮台是玩家花 1~2 格 + 1~2 人 + 弹药 + 建造成本换来的**正反馈**，被 HP 吃掉就失去意义；
  ② 海域1 是教程章，装上第一门炮之后本来就该变轻松；
  ③ **风险已确认**：`2004` 霰弹炮（3 目标 ×2.1 倍）对群怪的等效输出高于单体炮，海域2~3 的实际 TTK 会比表值短约 10~15%。**这是留给木桩验证的第一个待办**——若普通波清怪时间掉到 12s 以下，优先上调普通怪 HP 8~12%（《怪物系统》2.2 修正系数），**不要下调炮台伤害**（那会让"造炮"的爽感消失）
- 真正的平衡阀是**弹药**：单场遭遇耗 72 发（火炮房 32 + 火枪 40），工坊 Lv1 产 40 发/分钟、推进间隔 120 秒 → 供给 80 发/场，覆盖率约 111%。若实测覆盖率长期 >1.3，**优先削减弹药掉落、不要加怪血**；若 <0.9，先提工坊产出（见《船舱房间系统》6.1.1）
- 海域越高 D_r 越高（×1.75/海域），怪物 HP 按同速成长，保证 TTK 恒定
- **修正旧矛盾**：v3.2 曾出现"单人枪械 44 DPS 但队伍总 DPS 60"的不一致（44 是属性溢出到 200% 的理论上限，不是白装基准）。本节以"属性=需求、白装"为基准，上限值只在后期出现

**5. 已作废的旧规则**
- “每10点技巧+5%器械DPS”作废，统一为“属性÷需求→效率”模型
- SAN不再同时扣伤害与攻速，改为独立DPS乘区
- 真实伤害/固定附加伤害在MVP不投放，避免公式理解成本

**6. 暂不引入的机制**
- 通用闪避、通用命中：MVP默认必中，仅特定怪物技能施加命中惩罚
- 属性克制：武器只有物理/魔法两类，不做元素克制，控制理解成本

**7. 四类武器闭环（v3.2）**
- 四个属性各有主武器：力量→近战、技巧→枪械、智力→法器、精神→圣典，不存在“某属性没有输出路径”
- **主属性≠效率属性**是硬规则：枪械若也用技巧做效率，会变成单属性双吃（强度+间隔同源），故效率属性取智力；代价是枪械必须双属性，单技巧船员用枪械会明显偏弱
- 技巧与智力互为对方武器的效率属性（技巧→近战/法器/圣典，智力→枪械），形成闭环，避免封顶后成为废点
- 效率属性由武器配置而非全局写死：未来新增“以精神为效率属性”的仪式型武器时，公式与代码都不用改，只需配字段
- 圣典是条件输出：对非亡灵只治疗，治疗量受“单次≤目标HP×30%”压制，防止高精神+高释放效率形成不死队
- 数值验收：圣典HPS目标约为单只普通怪DPS的40%~60%；枪械DPS与近战持平但射程更远（脆皮换安全）

### 3.8 程序实现顺序（伪代码）

```
function calcHitDamage(attacker, defender):
    // 0. 圣典分流：对非亡灵不结算伤害
    if attacker.weaponCategory == HOLY_TOME and not defender.hasTag("UNDEAD"):
        return 0   // 交给 healTick 处理

    // 1. 命中（MVP可跳过）
    if not rollHit(attacker, defender): return 0

    // 2. 基础伤害：按武器类别取主属性
    mainStat = attacker.weaponMainStat()   // 近战=str / 枪械=dex / 法器=int / 圣典=spr
    ratio = clamp(mainStat / attacker.weaponMainReq, 0.5, 2.0)
    B = mainStat * K + attacker.weaponDamage * ratio + attacker.flatBonus

    // 3. 百分比修正
    P = clamp(1 + attacker.dmgBonus - defender.dmgReduction, 0.4, 2.0)
    dmg = B * P

    // 4. 暴击
    if rollCrit(attacker): dmg *= attacker.critMultiplier

    // 5. 格挡（固定减伤，最低保留10%）
    if rollBlock(defender): dmg = max(dmg - defender.blockValue, dmg * 0.1)

    // 6. 真实伤害与取整
    return max(1, round(dmg)) + attacker.trueDamage

function releaseEfficiency(unit):
    // 效率属性由武器配置：当前 枪械=int；近战/法器/圣典=dex
    stat = unit.effStatValue()        // 武器表字段 effAttr 映射到四维
    return clamp(stat / unit.effReq, 0.5, 2.0)

function releaseInterval(unit):
    return unit.baseInterval / releaseEfficiency(unit) / (1 + unit.speedMod)

function healTick(healer, allies):
    target = pickLowestHpRatio(allies)      // 射程内受伤比例最高者
    if target == null: return
    ratio = clamp(healer.spr / healer.weaponMainReq, 0.5, 2.0)   // 与伤害共用同一发挥率
    heal = (healer.spr * K + healer.tomeHealValue * ratio) * (1 + healer.healBonus)
    heal = min(heal, target.maxHp * 0.30)   // 硬上限
    target.hp = min(target.maxHp, target.hp + heal)

// 器械：mainStat=0，ratio=1，weaponDamage=器械基础伤害+炮弹加成；
//       攻速另走 roomEfficiency = clamp(操作属性/房间需求, 0.5, 2.0)
```

### 3.9 治疗与亡灵伤害（圣典）

**治疗目标选择**
- 自动选择射程内**受伤比例最高**的友方船员；无受伤目标时待机，不空放、不浪费间隔
- 治疗不走命中/暴击/格挡，也不吃守方减伤率，只结算“治疗量 × 治疗间隔”

```
治疗量与伤害同构，只把“武器效果值”换成圣典治疗值：
治疗量 = (精神 × K + 圣典治疗值 × 发挥率) × (1 + 治疗加成)
最终治疗 = min(治疗量, 目标HP上限 × 30%)
发挥率 = clamp(精神 ÷ 圣典主属性需求, 50%, 200%)
治疗间隔 = 圣典基础间隔 ÷ 释放效率 ÷ (1 + 攻速修正)
```

- 治疗加成来自词缀/技能（如“之祝福 治疗量+12%”），总上限 +50%
- 单次治疗上限（目标HP×30%）是硬约束：溢出部分直接丢弃，防止高精神+高释放效率形成不死队

**对亡灵伤害**
- 圣典对带“亡灵”标签的目标结算伤害，公式复用 3.1，但主属性=精神、伤害类型=魔法（吃目标魔抗）
- 对非亡灵目标只治疗、不结算伤害，不产生“0伤害”飘字，避免玩家误读
- “亡灵”标签由《怪物系统》配置（骷髅/幽灵/亡灵Boss等），战斗系统只读标签，不维护名单

**数值意图**
- 圣典是“队伍续航”位而非主力DPS：HPS 目标约为单只普通怪DPS的 40%~60%
- 亡灵关卡中圣典同时承担治疗与输出，成为该关卡的最优解，形成“关卡—配装”策略（不是无条件的万能解）

## 四、怪物类型与AI

### 4.1 两大类怪物

怪物分**海中怪**与**登船怪**两类，攻击目标完全不同：

| 类型 | 代表 | 攻击目标 | 是否登船 |
|---|---|---|---|
| 海中怪 | 巨型鱼类、海怪 | **直接攻击房间**，损毁后攻击船只耐久 | 否 |
| 登船怪 | 人形怪、爬行者 | 攀爬上甲板，攻击船员/器械 | 是 |

> 同一只Boss可兼具两种行为（如克拉肯用触手拍房间[海中怪行为]+小触手爬甲板[登船怪行为]）。

### 4.2 海中怪行为（攻击房间）

```
远海出现（progress 100）
    ↓ 游弋接近 10~14s（全程可被炮位/枪械/法器攻击，见 §1.3）
接触船舷（progress 20，不再前进，就地攻击）
    ↓
攻击目标房间（房间耐久↓）
    ↓ 房间耐久归零
房间损毁 → 该房间功能暂时停用，房间内船员自动转为修理状态
    ↓ 海中怪继续攻击已损毁房间
损失船只耐久
    ↓ 船只耐久归零
战斗直接失败
```

- 海中怪攻击优先级：**当前正在产出的房间 > 有人的房间 > 空房间**
- 玩家必须在船只被摧毁前击败怪物
- **海中怪的路程比登船怪长（10~14s vs 7~11s）**：体型大、游得慢，给了炮位更多轮开火机会。这也是"海中怪更肉但更好打"的平衡手段

### 4.3 登船怪行为（攻击船员）

```
远海出现（progress 100）
    ↓ 游弋接近 7~11s
      ├ 炮位 range 95：全程可打（94% 窗口）
      ├ 枪械 range 65：距离到 65 才开打（56% 窗口）
      ├ 法器 range 55：距离到 55 才开打（44% 窗口）
      └ 近战 range 20：海面全程哑火
    ↓ 接触船舷（progress 20）
攀爬 2.4s 硬直（全部远程 + 贴舷近战可打；瞭望台Lv3"弱点标记"作用于此时）
    ↓ 上甲板（progress 0）
甲板交战（就近攻击船员/器械；**近战从此刻起才输出**）
    ↓ 甲板无敌人或HP<30%概率
入侵舱室（就近攻击房间内船员）
```

**塔防视角的三条推论（设计者必读）**

1. **"怪还在路上"= 玩家的观察窗口**：海面阶段只有远程在打，这段时间玩家的唯一任务是看"打不打得掉"，并决定要不要按全员参战。
2. **攀爬 2.4s 是唯一的全火力窗口**：远程 + 近战同时能打，是爆发配置的价值所在。不要随便改这个值，除非同步改所有爆发数值。
3. **登船 = 漏怪**：近战接战的那一刻就是防线被突破的视觉信号。漏怪率（登船比例）是比"通关率"更敏感的难度指标，验收时要单独看。

### 4.4 行为差异
| 类型 | 行为特征 |
|---|---|
| 普通海中怪 | 持续攻击同一房间直至损毁 |
| 精英海中怪 | 带技能（如喷吐远程、自愈），优先攻击器械位 |
| 普通登船怪 | 直线接近，就近攻击 |
| 精英登船怪 | 优先攻击器械位/濒死船员 |
| Boss（海怪） | 多部位攻击：触手缠船舷/拍甲板/喷吐舱室；阶段转换（HP70%/30%）；高恐惧光环（持续SAN压制） |

> 怪物数值与行为参数以《怪物系统》v3.1 为准（本章只描述行为骨架）；HP/护甲/攻击已按塔防口径重算，不要再回到旧表。骷髅/幽灵/亡灵Boss 需带"亡灵"标签，供圣典判定伤害（见 §3.9）。

## 五、房间耐久与修理

### 5.1 耐久机制
- 每个房间有独立耐久值，被海中怪攻击时下降
- 耐久归零=房间损毁，**该房间功能暂时无法使用**（生产停摆、器械哑火）
- 房间损毁后若继续被攻击，伤害转为**船只耐久**损失
- 房间视为无闪避/无格挡单位，怪物对房间的伤害沿用第三章公式；房间减伤率由房间等级配置（建议Lv1 0%/Lv2 10%/Lv3 20%）

### 5.2 修理机制
- 损毁房间内的船员自动转为修理状态，**修理消耗木材**
- 修理速度取决于船员【技巧】属性，技巧越高修理越快
- 修理中船员不参与战斗
- 玩家可通过**拖拽高技巧船员到损毁房间**实现快速修理（核心操作之一）
- 修理完成后房间恢复全部耐久并恢复功能

## 六、船只耐久与战败惩罚

### 6.1 船只耐久
- 船只有总耐久值，海中怪攻击已损毁房间时扣除
- **船只耐久归零 = 战斗直接失败**

### 6.2 战败惩罚（v2.3 修订：不致死、不卡关）
| 惩罚项 | 内容 |
|---|---|
| 资源遗失 | 仓库中**资源类物品**（食物/淡水/木材/钢铁/魔晶等）遗失 30%~50%；装备/转职书/特性/贝壳币**不遗失** |
| 全员受伤 | 全员扣除**当前生命上限的 35%**，**最低保留 1 点，绝不致死**（不再触发死亡与复活流程） |
| 全员 SAN | 全员 SAN -15（只影响效率，不产生负面特性） |
| 房间与船体 | 房间耐久、船体耐久统一重置为 **30%**，需消耗木材修理（不是归零，避免回船即瘫痪） |
| 章节进度 | **当前章节关卡进度重置**，需从本章第 1 关重新推进 |
| 保留项 | 船员等级/属性/转职/特性/装备、仓库装备、图鉴进度、已解锁海域 **全部保留** |

> **设计意图（防卡关闭环）**：战败代价 = 时间 + 部分资源，不是战力清零。玩家被 Boss 挡住时，可以退回本章低级关卡反复刷资源、修船、补装备、刷图鉴适应度后再挑战，形成"打不过 → 回刷 → 再来"的正循环。章节进度重置带来重复收益的机会，而不是惩罚性倒退。
>
> **与死亡规则的关系**：战败不会击杀船员，因此不存在"战败 → 全员阵亡 → 复活看广告"的连锁挫败。船员死亡只可能由战斗中的单体生命归零触发，且可无限复活（见《SAN与特性系统》第四章）。

## 七、主动技能（2 个，v2.4）

> **定位：战斗中只有两个按钮。** 一个是"加把劲"（全员参战），一个是"撤"（传送逃跑）。两个都不造成直接伤害、都不是连招，只改变**防线的厚度**与**退出的时机**。
>
> 两个技能互不共享冷却：一场战斗里可以各用 1 次。

### 7.1 全员参战（弃岗迎战）

> **一句话**：把全船生产岗的人都拽上甲板打一架，代价是这期间的产出全部停摆、食物烧得更快。

**这是塔防里的"临时加塔"** —— 防线快被压垮时，用经济换火力。

#### 7.1.1 规则表

| 项 | 规则 |
|---|---|
| 技能名 | 全员参战 |
| 施放位置 | 战斗中常驻于界面右下角（与传送逃跑并列），非战斗隐藏 |
| 集结时间 | **5 秒**：在岗船员离岗跑向甲板，期间**不在岗位、也不参战**（火力空窗期） |
| 参战人员 | 所有在岗船员（生产/功能房）全部转为甲板战斗单位，使用各自装备武器 |
| 无武器者 | 使用「船用工兵铲」：伤害 = `力量 × 0.5`，间隔 2.0s，射程 20（只打贴舷/甲板），不吃装备加成 |
| 持续 | 直到**战斗结束**（场上连续 5 秒无怪）自动解散；玩家也可手动提前解散 |
| 结束回岗 | 自动回到原岗位，**3 秒内恢复 100% 岗位效率**，无额外惩罚 |
| **代价①·生产停摆** | 动员期间**全部生产房/功能房产出归零**（种植房、钓鱼房、医务室、动力舱全部停） |
| **代价②·食物加速** | 动员期间食物消耗 **×3**（基础 1.0 食物/人/分钟 → 3.0） |
| **代价③·能源净耗** | 动力舱无人 → 能源产出 0，但全船仍在耗能，能源条只降不升。**v3.6 合并后这是唯一的能源房，动员的代价变重了** |
| 冷却 | 每场战斗 **1 次** |
| 不可开启条件 | 食物 < 储备上限的 20%，或食物房全毁无法补给（按钮置灰 + 提示） |
| 强制中断 | 动员中食物归零 → 立即解散，全船 **SAN -5**（饥饿），并触发一次「饥饿」飘字 |
| 与逃跑的关系 | 动员中可直接施放传送逃跑；逃跑成功则动员自动解散（人跟着传走） |

#### 7.1.2 战斗增益参考（配平用）

以 1 级船 9 人（3 甲板 + 6 生产岗）为例：

| 状态 | 可战单位 | 有效 DPS（海域1白装） | 说明 |
|---|---|---|---|
| 常态 | 3 甲板远程（+ 已建的炮台） | ≈35（3×11.7），带 1 门炮 ≈42 | 生产岗照常产出 |
| 动员后 | 9 甲板（+ 炮台） | ≈35 + 6×6 = **71**（带 1 门炮 ≈78） | 生产岗多持工具/低配武器，单价按 6 DPS 估 |

- 火力约 **×2.0**（71÷35，带炮 78÷42≈1.86），但换来的是 0 产出 + 3 倍食耗
> v1.15 修正：舷炮删除后常态 D_r 从 45 降到 35，若生产岗仍按 8 DPS 估，动员倍率会冲到 2.4 倍、破 1.8~2.2 红线。生产岗持的是工具不是武器，**6 DPS 是更合理的估值**，倍率随之回到 2.0
- 这个倍率是**配平红线**：若动员后 DPS 超过常态 3 倍，技能会从"应急"变成"必开"，玩家会每场无脑点 → 应回到 1.8~2.2 倍

#### 7.1.3 设计意图

- **给"打不过"提供一个非逃跑的解法**：以前只有"拖人"和"跑"，现在多了一个"拼命"。三种应对的代价分别是：拖人（时间成本/顾此失彼）、动员（经济成本）、逃跑（进度成本）。
- **把食物轴从"被动挨饿"变成"主动开销"**：食物原本只是缓慢消耗的压力条，动员让它变成一个**可支配的战斗资源**，食物储备第一次有了战术意义。
- **自然形成"什么时候开"的决策**：开早了食物白烧、生产白停；开晚了防线已经破了。判断依据是海面击杀率——屏幕上还有几只怪没死。
- **与"远程为主"互补**：动员上来的生产岗大多是近战/工具（射程 20），只能打贴舷和甲板的怪。所以动员是"堵漏"而不是"加强远程火力"，不会破坏远程主力的定位。

### 7.2 传送逃跑

> **定位：用能源换命的退出手段。** 不造成伤害、不打断敌人，只让玩家"体面地认输"。玩家除了拖拽和全员参战，这是第三个可点的按钮。

#### 7.2.1 规则

| 项 | 规则 |
|---|---|
| 技能名 | 传送逃跑 |
| 施放位置 | 战斗中常驻于界面右下角，非战斗状态隐藏 |
| 施放代价 | **持续消耗能源槽存量**：读条期间每秒扣 8 点能源（共 8s ≈ 64 点） |
| 读条时长 | **8 秒**，读条期间怪物继续攻击、房间继续掉耐久、船员照常掉血 |
| 生效条件 | **读条走完才生效**，中途打断则本次施放作废，已消耗能源不返还 |
| 中断条件（任一） | ① 能源归零 ② 能源房（动力舱）耐久归零 ③ 船只耐久归零 ④ 玩家主动取消 |
| 技能冷却 | 每场战斗 **1 次**（失败不返还次数） |
| 逃跑成功 | 传送脱离，回到**最近一个已通关章节的安全锚点**，玩家可手动切换章节 |
| Boss 战逃跑 | 允许，但**本章节关卡进度重置**，需从第 1 关重新推进 |
| 读条期间的 UI | 屏幕边缘由暗转亮（空间扭曲），读条框居中偏下；能源条同步实时下降并变红 |

### 7.3 设计意图（逃跑）
- **把"撤退"变成一个需要付出代价的决策**：8 秒读条 + 持续耗能，意味着玩家要提前判断"还能不能打"，而不是快死了再跑。跑得早，能源保得住；跑得晚，能源被抽干还可能跑不掉。
- **主动技能只服务"保命"与"加厚"，不服务"输出"**：两个技能都不直接造成伤害，不违背"不给直接攻击操作"的红线。
- **与能源压力轴咬合**：逃跑抽的是全船总闸的资源，逃一次会让后续生产停摆一段时间，形成"逃跑也很贵"的心理重量。
- **两个技能已是上限**：再多一个，玩家就会开始"按技能"而不是"调人"。取"加火力"与"退出"两个极端，中间地带留给拖拽——这是本作的操作取舍。
- **两技能的经济代价不同构**：全员参战烧**食物**（存量资源，可再产），传送逃跑烧**能源**（全船总闸，恢复慢）。玩家在"硬撑"和"放弃"之间选时，选的是两种不同的资源负债。

### 7.4 与"不做战前准备"的关系
战斗**没有战前布阵 / 加固 / 关舱门**等准备阶段，怪物来袭即开打。玩家的全部战斗决策只有三类：
1. **拖拽船员**（战斗中随时可做，高频操作）
2. **全员参战**（一场 1 次，把生产岗变成防线）
3. **传送逃跑**（一场 1 次，用能源换退出）

> 明确不做：战前预警布置、船舱加固、陷阱预设、手动开炮、技能连招、技能树主动技。战场信息（怪物从哪侧来）由瞭望台被动提供，不转化为操作步骤。

## 八、Boss战

- 入口：海域终点节点，主动发起
- 门槛校验：提示全员当前SAN与图鉴适应度，未达标给出“建议先刷低级海域脱敏”提示（不锁死，可强闯）
- 战斗中：Boss恐惧光环持续扣SAN（可被精神属性/特性/忏悔室增益抵抗）
- 失败条件（任一）：**船体耐久归零**（主判负条件）／全员死亡且均未复活超过 20 秒／全员崩溃离岗累计超时 30 秒
- 注意：单体死亡**不构成失败**，船员可无限复活；只有"没人能操作这艘船"才算输
- 通关结算：按各船员SAN判定特性获得（≥90正面/<30负面），解锁该海域岛屿自动探索扫荡

## 九、玩家在战斗中的操作清单（v2.4）

**战斗中可做的操作只有 3 类：拖拽 + 全员参战 + 传送逃跑。**

| # | 操作 | 时机 | 作用 | 频次 |
|---|---|---|---|---|
| 1 | **拖拽船员增援甲板** | 怪物上船 | 集火/补位 | 高频 |
| 2 | **拖拽濒死船员入医务室** | 任何时刻 | 保命（脱战） | 高频 |
| 3 | **拖拽崩溃船员入忏悔室** | SAN 危险 | 止损（恢复效率） | 中频 |
| 4 | **拖拽高技巧船员到损毁房间** | 房间被海中怪损毁 | 快速修理（核心操作） | 中频 |
| 5 | **拖拽死亡船员位置的空岗补人** | 船员阵亡后 | 维持产出/火力 | 中频 |
| 6 | **拖拽高技巧船员入火炮房** | 战前/平静期/战中 | 上炮位→开始自动开火；技巧决定射速（效率≤200%） | 中频 |
| 7 | **全员参战（主动技能）** | 漏怪过多/防线快破 | 生产岗上甲板，火力约×2；代价=停产+食耗×3 | 每场 1 次 |
| 8 | **传送逃跑（主动技能）** | 判断打不过时 | 读条 8s、持续耗能源、走完才生效 | 每场 1 次 |

**明确不做（红线）**
- ❌ 不给任何直接攻击/开炮/点技能打伤害的操作，保持"调度模拟"而非"动作游戏"
- ❌ 不做战前准备阶段（不布置、不加固、不预设陷阱），怪物来袭即开打
- ❌ 不做第三个主动技能；两个已是上限（加火力 + 退出）
- ❌ 不做手动瞄准、闪避、格挡等操作
- ❌ 不做"暂停战斗慢慢布阵"，塔防的压力来自实时

> 设计逻辑：**拖拽是常态，两个技能是例外。** 玩家 95% 的手部动作应该是"把某个人从 A 拖到 B"，而不是点按钮。两个技能各占据一个极端——"我还能打"与"我不打了"——中间的所有判断都留给拖拽。

## 十、战斗掉落

- 装备（部位随机，稀有度按海域难度）、材料（铁/木材/魔晶/稀有材料）、**弹药**
- 装备掉率占装备总产出的70%（锻造30%），详见《装备与锻造系统》
- Boss必掉紫装起步，概率橙装（橙装仅掉落产出）

### 10.1 弹药掉落（v3.0 新增）

| 来源 | 弹药 | 折算（每小时） |
|---|---|---|
| 普通怪 | **1 发/只** | 约 107 发 |
| 精英怪 | **5 发/只** | 约 35 发 |
| 小Boss | **15 发/场** | — |
| 大Boss | **30 发/场** | — |
| 沉船残骸（打捞） | 20~40 发 | — |
| 商人岛（购买） | 50 发 / 200 贝壳币，每岛限 3 次 | — |

> **掉落只占需求的约 7%**，工坊才是主产地（40 发/分钟 = 2,400/小时，需求 2,160/小时）。这个比例是刻意的：**掉落是"意外之喜"，工坊才是"必须经营"**。如果把掉落提到 30% 以上，玩家会觉得"不用建工坊也行"，那就抽掉了 MVP 最重要的产能取舍。
