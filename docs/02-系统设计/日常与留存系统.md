# 《恐惧之海》微信小游戏版 - 日常与留存系统

> 版本：v2.2（经济结构改为"战斗掉落为主、任务辅助"；分享三选一合规化）  
> 涵盖：每日任务、7日登录、图鉴成就（任务化）、游戏币经济、分享/广告触发比例。

## 一、每日任务

### 1.1 任务模板（每日刷新5个，随机抽取）

| 任务类型 | 示例 | 奖励 |
|---|---|---|
| 通关类 | 通关1个海域关卡 / 击败1只精英怪 | 游戏币+木材 |
| 钓鱼类 | 钓上5条鱼 / 钓上1条蓝色品质鱼 | 游戏币+食物 |
| 探索类 | 探索1次岛屿 / 捞取3个漂浮物 | 游戏币+铁 |
| 属性成长类 | 任意船员属性+1 / 完成1次转职 | 游戏币+属性经验道具 |
| 建造类 | 建造/升级1个房间 | 游戏币+木材 |
| 修理类 | 修理1个损毁房间 | 游戏币+木材 |

- 每日0点刷新，完成后自动发放奖励
- 任务难度随海域进度动态调整
- **奖励配额（v2.2 定）**：单任务贝壳币 **60~70**，5 个合计 300~350，占日入约 15%
- 任务定位是**辅助来源**：它的作用不是养活玩家，而是"给一个每天上线的理由"与"告诉新手该干什么"。真正的收入在战斗掉落里

### 1.2 活跃度
- 每个任务贡献活跃度，累计活跃度达档位领取额外游戏币
- 满活跃度可**三选一**（分享/看广告/游戏币）再领一次，三条路径等价可见

## 四、游戏币经济

### 4.1 设计原则
**游戏币长期处于"不够用"的状态**——锻造、购买、清特性等核心消耗都要游戏币。

但**获取的主路径是打怪，不是看广告**：玩家想变强 → 出海去刷 → 拿到币与装备。广告只提供"省时间"的选项（离线翻倍、再捞一次、锻造保底），不提供"唯一的钱路"。这样"缺钱"驱动的是**行为**（多打一场），而不是**付费焦虑**（怎么又要看广告）。

合规红线见第五章。

### 4.2 游戏币用途（消耗点）

| 用途 | 说明 |
|---|---|
| 锻造装备 | 按装备等级/品质消耗，是最大消耗口 |
| 神秘商店购买 | 商人岛/神秘商店商品 |
| 清除负面特性 | **忏悔室（MVP 第 2 章）**：① 直接 300 币/条（固定不递增） ② `虚空晶 ×1 → 赎罪券 ×1` 挂机加工，不花币 / 商人岛赎罪券 M19（第 1 章唯一渠道） |
| 船体升级 | 船舱界面直接升级（格数/耐久/甲板战斗岗），原船坞岛已删 |
| 转职任务加速 | 部分转职任务可用游戏币加速完成 |

### 4.3 游戏币来源（v2.2 重排：**掉落为主，任务辅助**）

| 来源 | 目标占比 | 说明 |
|---|---|---|
| **战斗掉落（普通/精英/Boss）** | **≈65%（主来源）** | 挂机与刷章节的主要收入。海域1 约 3,000/小时（折算见《怪物系统》5.2），海域越高越高 |
| **每日任务** | **≈15%（辅助）** | 稳定、量小。只保证"每天回来有事做"，不承担主要收入 |
| 图鉴成就（鱼/怪/装备/特性） | ≈8% | 一次性，中后期自然递减 |
| 奇迹之海里程 / Boss 首通 | ≈7% | 阶段性大额 |
| 激励视频 | ≈5% | 只作为"想更快"的加速，不作为必需品 |

> **为什么改**：旧方案让广告补 30~40% 的货币缺口，玩家体感是"被逼看广告"；改以掉落为主后，**刷怪本身就是赚钱**，与"打不过就回刷"的防卡关设计同源——玩家退回低级海域不是惩罚，是去收钱。
>
> **必须同步调整的一点**：任务奖励要跟着降。若任务仍按旧量发放，会与掉落叠加造成通胀。本节给出配额：**5 个每日任务合计 300~350 贝壳币，活跃度满档再补 100**（约占日入的 15%）。

### 4.4 平衡目标

- **纯游戏内产出 ≈ 总需求的 90~95%**（旧版为 60~70%）
- 广告只补 5~10%，定位从"必需"改为"加速"
- 日产对照（以海域1 为例）：

| 项 | 贝壳币 |
|---|---|
| 战斗掉落（日均有效战斗 40 分钟） | ≈2,000 |
| 每日任务 + 活跃度 | ≈400 |
| **日入合计** | **≈2,400** |
| 主要消耗：锻造 1 件蓝装 | 300~800 |
| 主要消耗：船只升 1 级 | 1,000~3,000 |
| 主要消耗：清 1 条负面特性 | 300（固定） |

> **风险提示（商业侧）**：货币不靠广告之后，IAA 的收入会集中到"买时间/买确定性"的点位（离线收益翻倍、再捞一次、锻造品质保底、商人岛刷新），而不是"买货币"。这条路径的 eCPM 与人均观看次数**必须在上线前实测**；若收入不足，**优先增加非货币型广告价值，不要回头让货币依赖广告**——那会把玩家重新推回"被逼看广告"的体感。

## 五、分享与广告触发（v2.1 修订：合规化改版）

### 5.1 铁律：任何触发点都是"三选一"，不强制分享

所有分享/广告触发点（死亡复活、离线翻倍、锻造保底、再捞一次、商人岛刷新、再抛一竿、满活跃再领、游戏币获取等）**必须同时提供三条等价路径**：

| 路径 | 代价 | 是否必需 |
|---|---|---|
| 分享给好友/群 | 1 次分享 | 可选，绝不强制 |
| 看激励视频 | 1 次广告（受每日 ≤5 次频控） | 可选 |
| 消耗游戏币 / 直接跳过 | 固定游戏币或零成本 | 可选，保证不卡死 |

> **合规红线**：不得出现"必须分享才能继续游戏 / 才能领奖 / 才能复活"的设计；不得用倒计时、遮挡、无法关闭的弹窗诱导分享。分享是**选项**，不是**关卡**。

### 5.2 推荐权重（按登录天数递减，只影响默认高亮）

| 天数 | 默认高亮分享 | 默认高亮广告 | 说明 |
|---|---|---|---|
| 第1天 | 80% | 20% | 前 3 次触发默认高亮"分享"，但玩家可直接选广告或游戏币 |
| 第2天 | 60% | 40% | — |
| 第3天 | 50% | 50% | — |
| 第4天 | 40% | 60% | — |
| 第5天 | 30% | 70% | — |
| 第6天 | 20% | 80% | — |
| 第7天+ | 20% | 80% | 稳定 20/80，保留少量分享用于裂变 |

- "天数"按**登录日**计算（离线不计）
- 该比例**只决定默认高亮项与推送文案**，三条路径始终全部可见、全部可点
- 死亡复活点位默认高亮分享（情感时刻转化率高），但同样可改选广告/游戏币

### 5.3 分享内容：从"求助力"改为"炫耀"
| 旧做法（风险） | 新做法（安全） |
|---|---|
| 分享求好友助力、砍一刀、凑人数 | 分享自己的航海截图：里程纪录、稀有鱼、Boss 首杀、船员墓碑 |
| 分享后好友必须点击才生效 | 分享即完成，好友是否点击不影响奖励 |
| 强制分享才能复活 | 分享/广告/游戏币三选一 |

> 裂变逻辑从"求助"转成"晒成绩"：玩家愿意分享的是**自己的高光**，不是**自己的困境**。这既符合平台规范，转化质量也更高。

### 5.4 设计意图
- 新用户期（前 3 天）靠**默认高亮的分享**降低广告反感，同时保留广告选项给不愿社交的玩家
- 老用户期（第 4 天起）靠广告变现，此时玩家已建立粘性
- 三选一结构让"分享阈值高"的玩家也能顺畅推进，避免因拒绝分享而流失（这是旧方案最大的隐性流失点）

## 六、新手引导

### 6.1 基础生存循环引导（仅保证基础闭环）
```
第1步：拖拽船员到划桨舱 → 获得能源
第2步：建造雨水收集器，安排船员 → 获得淡水
第3步：建造钓鱼房，安排船员 → 获得食物
完成判定：能源、淡水、食物同时持续产出60秒
```
- 仅引导至三基础资源房运转，其余功能在**玩家首次接触时条件触发引导**
- 例：首次SAN崩溃→引导忏悔室；首次建造工坊→引导锻造；首次获得转职书→引导转职

### 6.2 功能开启引导触发条件

| 触发条件 | 引导内容 |
|---|---|
| 能源条首次耗尽 | 提示建造/升级能源房 |
| SAN首次进入崩溃 | 提示忏悔室（第 2 章起）/拖出战斗 |
| 首次获得转职书 | 引导转职界面 |
| 首次房间损毁 | 引导拖拽高技巧船员修理 |
| 首次Boss战败 | 提示逃跑回低级海域刷资源 |
