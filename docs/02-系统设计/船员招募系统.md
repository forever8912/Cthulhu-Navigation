# 《恐惧之海》微信小游戏版 - 船员招募系统设定

## 一、船员招募概述

船员招募系统位于港口的酒馆建筑中，玩家可以消耗金币招募不同类型的船员。船员提供属性加成，增强船只的战斗和探索能力。

## 二、酒馆解锁

### 解锁条件
- 玩家拥有3名船员
- 玩家等级达到10级

### 酒馆等级
- 1级：基础船员招募
- 2级：解锁稀有船员（消耗金币×1000升级）
- 3级：解锁史诗和传说船员（消耗金币×3000 + 神秘碎片×15升级）

## 五、船员招募机制

### 招募流程

```
进入酒馆
    ↓
选择招募方式（单次/十连）
    ↓
消耗金币
    ↓
显示招募动画
    ↓
获得随机船员
    ↓
加入船员列表
```

### 招募方式

| 招募方式 | 消耗 | 概率加成 | 说明 |
|----------|------|---------|------|
| 单次招募 | 金币×200 | 无 | 随机获得1名船员 |
| 十连招募 | 金币×1800 | 稀有+概率+5% | 随机获得10名船员，至少1名稀有+ |

### 招募概率

| 稀有度 | 单次招募概率 | 十连招募概率 |
|--------|------------|-------------|
| 普通 | 60% | 55% |
| 优质 | 25% | 25% |
| 稀有 | 10% | 13% |
| 史诗 | 4% | 5% |
| 传说 | 1% | 2% |

## 六、船员管理

### 船员列表
- 显示所有已招募的船员
- 显示船员属性和技能
- 可查看船员详情

### 船员升级

| 等级 | 升级消耗 | 属性提升 |
|------|---------|---------|
| 1→2 | 金币×100 | 主属性+1 |
| 2→3 | 金币×300 | 主属性+1，次级属性+1 |
| 3→4 | 金币×600 | 主属性+1，次级属性+1 |
| 4→5 | 金币×1000 + 神秘碎片×5 | 主属性+1，次级属性+2 |

### 船员解雇
- 解雇船员获得部分金币返还（50%招募消耗）
- 已升级船员返还30%升级消耗
- 解雇后船员消失，无法恢复

## 八、船员加成计算

### 属性加成计算
- 所有船员的属性加成叠加
- 加成效果直接作用于船只和角色

### 被动技能叠加
- 相同类型的被动技能效果叠加
- 叠加上限：50%

### 存储内容

### 存储方式
- 本地存储（游客账号）
- 云端存储（微信账号）

## 十一、船员与其他系统的关联

### 与航海系统
- 船员属性影响航行能力
- 船员被动技能影响航行效果

### 与船只系统
- 船员属性叠加到船只属性
- 船员数量影响物资消耗

### 与战斗系统
- 船员属性影响战斗能力
- 船员被动技能影响战斗效果

### 与任务系统
- 部分任务要求拥有指定数量船员
- 任务奖励可能包含船员招募券

### 与商店系统
- 商店可购买船员招募券
- 招募消耗的金币可通过任务和探索获得

## 程序接入说明（v1.25：`05_船员与技能.xlsx`——招募侧）

3 sheet：船员生成表（roll 规则）→ 船员名称表 → 船员外貌表；初始船员表为开局直发数据。

- **生成流程**：rarity 按 weight 抽 → 性别按 gender_weight_* → 四维在 attr_roll_min~max roll + main_attr_bonus → 特性按 trait_pos_count/trait_neg_count 从 07 特性表抽 → 配件按 accessory_chance
- **外貌**：`look_json` 格式 = `{"skin":"1xxx","hair":"2xxx","face":"3xxx","brow":"4xxx","eye":"5xxx","mouth":"6xxx","outfit":"7xxx"}`（分层合成，`layer` 定叠放序，`palette_json` 换色）；竞技场虚拟船长、酒馆招募共用此管线
- **名称**：按 gender + rarity_allow 过滤后加权抽
- 校验：`verify_skill.py`（含外貌分层完整性）
