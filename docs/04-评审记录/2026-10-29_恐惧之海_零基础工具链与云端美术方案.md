## 1. 零基础能不能做完：能，但要重定义目标

【建议】目标不是"学会 Cocos"，而是**永远不需要学**。三个硬条件，缺一个就别启动：

| # | 条件 | 说明 |
|---|---|---|
| 1 | **授权 AI 完全掌控代码库** | 你不 review diff、不读代码。这是零基础唯一可行模式，代价是代码可维护性不由你控制 |
| 2 | **所有命令行/构建一键化** | 见 §3，做不到就别做 |
| 3 | **只按"能玩"验收** | 里程碑验收 10 条以内，只玩不看码 |

**不换引擎**。Cocos Creator 的构建面板是点击式 GUI，对零基础反而比纯 CLI 引擎友好；3.8 是 LTS，教程语料多、AI 幻觉率低于 3.9。零基础三大致命障碍：环境/构建任一环断链、无法判断 AI 写得对不对、AI 幻觉 API（本地能过、微信端崩）。

## 2. 代码工具推荐

### 主选：**TRAE**（字节）
- 已升级 **IDE + Work（原 SOLO）+ Builder** 三模式；Work 模式 = AI 端到端主导，正是零基础需要的"黑盒感"
- 中文界面、内置 Doubao / DeepSeek 等模型、无需自备 Key
- 基础版免费，Pro 约 ¥25/月（*媒体横评口径，非官方*）
- 关键能力：能自主接管终端与构建，**不必你自己敲命令**

### 备选：**CodeBuddy**（腾讯）
- 插件 + IDE + CLI 三形态，横评称完全免费（*媒体横评口径*）
- 后期若你想逐步看懂项目，它的 Plan 模式比 Work 模式更利于过渡到"可审查"
- ⚠️ **利益披露：本次评审本身运行在 CodeBuddy 环境**，故列为备选而非主选

### 明确排除

| 工具 | 排除理由 |
|---|---|
| Cursor | $20/月、英文界面，核心价值是**人工审阅 diff** —— 零基础用不到它最贵的能力 |
| Claude Code | 纯 CLI + 英文终端 + 按量计费，命令行本身就是障碍 |
| Lovable / Bolt.new | 只产 Web 应用，做不了微信原生分包工程 |

**建议：先只用 TRAE 跑满四周**，不够再加第二个。单人最贵的是工具切换成本，不是订阅费。

## 3. 零基础工作流：保留全代码驱动 + 五条防黑洞

上轮定的"全代码驱动（无 Prefab、无编辑器拖引用、运行时 `new Node()`）"**保留**，但理由变了：不是为了优雅，是为了**消灭你无法复现的手工步骤**（在编辑器里拖 200 根引用线，AI 写不了、你也学不会）。

补五条防"AI 写了三万行、你完全不知道对不对"：

1. **需求先行**：每个模块先出 ≤1 页中文《做什么 + 验收清单》，你拍板后才准写代码
2. **规模上限**：单文件 ≤300 行、单模块 ≤5 文件
3. **变更预算**：一次请求 ≤3 文件、≤300 行；超限必须拆
4. **每模块自带可视化自检**：游戏内隐藏"自检"按钮，跑 15~25 条断言，只显示绿/红，不显示代码
5. **数值文案外置**：改表改 CSV，不改代码

### 必须一键化的六件事（AI 的交付形态）

| 环节 | 交付形态 |
|---|---|
| 环境安装 | `setup.bat` 双击 → 结尾 ✅/❌ 清单 + 逐图截图手册 |
| 构建导出 | `build_wechat.bat` 双击（或交 TRAE Work 模式直接做） |
| 导表 | `watch_tables.bat`：丢进 Excel 自动出 JSON 并校验字段 |
| 图集打包 | `assets_pipeline.bat`：原图目录 → 压缩 + 拼图集 + 清单 |
| 真机预览 | 逐图手册 + 游戏内"打开远程日志"按钮 |
| SDK 接入 | 封装层 + 自检页显示"登录/广告：通过/未通过" |

**原则：能双击就不敲命令，能截图就不看日志。**

## 4. 卡住时的自救动作（零基础可执行）

统一动作：截图或复制全文 → 连同一句固定话发给 AI。**不要自己读日志。**

| 场景 | 你该说什么 |
|---|---|
| Cocos 构建报红 | 「构建失败，我不懂代码，只告诉我要点哪几步，不要解释原理」+ 复制日志 |
| 真机白屏 | 手机开调试截 vConsole →「白屏，日志在此，请列 3 个可能并按概率排序」 |
| 首包超 4MB | 跑 `size_report.bat` 贴体积表 →「超了，先告诉我砍哪些图」 |
| AI 写出不存在 API | 自检页内置 API 白名单校验，不过直接回滚 |
| AI 改坏旧功能 | 跑回归自检页，红项截图 + 双击 `rollback.bat` 回上一 tag |

质保靠三件不依赖编程能力的东西：**里程碑可玩清单 ≤10 条**、**AI 强制写测试（你只看 pass/fail 计数）**、**Git tag + 一键回滚**。外加每 2 周一次陌生人试玩（录屏给 AI）。

## 5. 云端美术方案

### 5.1 平台组合（按环节分选）

| 环节 | 主选 | 备选 | 依据（2026-10 检索，第三方评测口径） |
|---|---|---|---|
| 概念稿 / 风格母版 | **Nano Banana Pro**（Gemini 3 Pro Image） | 即梦（国内直连） | NBP 多参考图一致性最强，一次保 5 角色 / 10 物件，最高 4K |
| 关键姿势（190 组） | NBP | Midjourney V8.1（`--oref`+`--ow`+`--seed`） | MJ V8.1 于 2026-04-30 发布、06-10 起默认，`--cref` 已废弃；Omni Reference 约 2 倍算力 |
| 像素化 | **云端无解** → AI 生成的量化脚本 | 云端 ComfyUI 色板节点（违背零编程） | 扩散模型输出连续色，MJ/即梦/NBP 均不提供"映射到固定色板"参数 |
| 补间 | **需实测** | 见 5.2 | 云端目前无确定解 |

### 5.2 补间：五条路裁决

| 路 | 裁决 |
|---|---|
| **图生视频再抽帧** | 【推断】对像素风**大概率不可行**：视频模型输出连续色调 + 运动模糊，抽帧后每帧颜色与边缘都不同，与 16 色索引 + 像素网格直接冲突。**只投 2 小时做 1 只怪 1 个动作的 spike** |
| **云端 ComfyUI + AnimateDiff 模板** | 技术最可行，但需 AI/他人预置 workflow JSON，你只点 Run → 模板可得性**需实测** |
| **云端 SD + 自训 LoRA** | 每只需 20~30 张转面图，38 只不经济 → 否决 |
| **买现成像素素材改色** | 全量授权与风格命中风险高 → 仅可用于 MVP 3 只验证 |
| **部件化动画** | ★ **推荐主路**：怪物拆部件，靠引擎位移/旋转出动作，帧数 910 → 300~400 |

**结论：910 帧的补间在云端不会显著下降**（22.8 人日，最多省 10~25%），除非走部件化或 ComfyUI 模板成功。

### 5.3 16 色色板与一致性

- **量化必须由脚本完成**：降采样 → 最近邻 → LAB/ΔE 最近色映射到 16 色（可选 Bayer dither）→ 越界统计 → 人工 Aseprite 精修
- **一致性打法**：先出 3~5 张风格母版（同 prompt 模板 + 同 seed + 记录完整模型版本串）→ 母版作为所有后续生成的参考图 → 每只怪锁 seed + 模型版本 + 参考图 hash → 写入 `manifest.csv`
- **应对云端模型静默更新**（MJ V8.1 已发生过默认版本切换，云端方案下风险更高）：每批前后各生成一张 **canary 母版图**比对，超阈值即冻结该批次；不跨月批量出图；保留源图与参数 JSON

### 5.4 脚本形态（你只做三步）

全部由 AI 生成：**把图放进 `in/` → 双击 bat → 把 `out/` 或报错截图发回 AI**。严禁改代码、严禁敲命令行。

`00_setup.bat` / `01_quantize.bat` / `02_rename.bat` / `03_anchor.bat`（foot-center 对齐）/ `04_pack.bat` / `05_validate.bat`，外加 `run_all.bat`。每个脚本先跑 3 张样本自检。

### 5.5 成本（量级，需实测）

- 38 只 × 5 状态 = 190 组，按每组抽卡 8~12 次 → **约 1500~2300 次生成**
- 单次等待 10~60 秒（Omni Reference 更慢）→ 纯等待 **4~38 小时**（不含排队）
- 先用免费额度（NBP / 即梦每日赠送，媒体称即梦约 60 积分/天、不累积）；付费档 MJ 为 $10~$120/月订阅区间
- **月度预算 ¥0~300，需实测，不预测**
