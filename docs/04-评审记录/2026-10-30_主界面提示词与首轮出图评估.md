# 主界面提示词与首轮出图评估

> 日期：2026-10-30 ｜ 依据：`评审/2026-10-30_美术风格选型_市场与AI双视角.md`（深海哥特：鸦翎笔剪影 + 旧纸 UI + 5 色）
> 出图工具：本轮用 WorkBuddy 内置图像生成（通用扩散模型），**非最终生产平台**，仅用于验证风格方向与提示词结构
> 产出图：`评审/概念图/` 下 4 张

---

## 0. 结论

1. **风格方向成立**：鸦翎笔 + 旧纸 + 5 色在出图上直接可用，第一眼就能传达"暗黑航海 + 剖面经营"，符合《Darkest Dungeon》那条"一张截图说清承诺"的判据。
2. **主界面不能用一张整图**。三版暴露的同一个问题是：**氛围与可读性在单张图里互斥**。必须拆层（背景 / 纸 / 剖面 / UI 分层出图，引擎拼装）。
3. **胜出的是 v3「旧纸图纸」**——它同时满足 §4.1「船舱剖面可读性优先」和 §4.3「剪影部件化」两层要求，且旧纸底天然承载 UI。

## 1. 三版对比

| 版本 | 构图 | 优点 | 硬伤 | 判断 |
|---|---|---|---|---|
| **v1 完整界面**（含按钮） | 上半海面+灯塔 → 中部船体剖面 → 底部 3 个空白羊皮按钮 | 分区清楚，能直接看出"这是个竖版游戏的首页" | 船内太暖太亮，像酒馆不像鬼船；按钮纸太白抢焦点 | 参考构图层级，**不采用**配色 |
| **v2 黑底氛围** | 上部海面灯塔 → 中部近乎全黑的剖面 → 底部留白 | 冷、压抑、氛围最贴克苏鲁 | **房间分不清**，玩家看不到有几间舱、人在哪 | 只可用于加载页/过场，**不可作主界面** |
| **v3 旧纸图纸** | 顶部海面+灯塔 → 中部大张烧边羊皮上的船体剖面线描图 → 底部暗区留按钮位 | **三层甲板、房间分隔、船员剪影全部可读**；旧纸质感直接统一了 UI 语言 | 船员姿势偏"热闹"（像集体出工），不够疲惫/压抑；纸面占比过大会压住氛围 | **采用为基线** |

v3 实际图像同时验证了三件此前只是推断的事：
- **色数真的可控**：画面主体就是黑 + 米黄 + 两点暖黄 + 一点青，接近天然 5 色，后续量化几乎无损。
- **剪影真的够用**：船员只是黑块，但"在拉绳/在搬货/在发呆"都能读出来——这正是 §4.3 部件化成立的前提。
- **AI 真的不擅长"可拆部件"**：三张全是整幅插画，没有一张输出可直接切成部件。**部件必须单独下 prompt 生成**，不能靠切图。

## 2. 推荐提示词（v3 基线，可直接复用）

### 2.1 英文主 prompt（MJ V8.1 / Nano Banana Pro / SDXL 通用）

```
Mobile game main menu, vertical 9:16. Deep-sea gothic crowquill ink illustration.
The frame is dominated by a large sheet of aged parchment, edges torn and burnt,
laid over a dark background. Drawn on the parchment in fine sepia-black ink linework
is a shipbuilder's cutaway plan of an old wooden ship hull seen from the side:
three decks divided into clearly separated compartments with visible wooden ribs,
beams and bulkheads, sparse weary black silhouette crew figures at their stations,
faint warm lamp washes in two compartments and one small phosphor cyan glow deep in the hold,
thin rust red accent lines marking the waterline.
Above the parchment, the top fifth shows a dark foggy sea and a distant lighthouse
with a faint cyan beam. Bottom fifth fades into darkness reserved for interface buttons.
Palette strictly limited to abyss black #0B0E14, aged paper beige #D8CFB8, sepia ink,
phosphor cyan #4FD1C5, lamp yellow #D9A03C, rust red #9C3F35.
Crisp hard edges, flat clean shapes, readable compartments at thumbnail size,
aged paper grain, ink speckles, heavy vignette, lighting from upper left.
```

### 2.2 中文 prompt（即梦 / Seedream，中文理解更顺）

```
竖版手机游戏主界面，深海哥特风，鸦翎笔钢笔插画。
画面中央是一大张烧焦边缘的旧羊皮纸，铺在黑暗背景上。
纸上用赭黑细线画出老木船的侧视解剖图：三层甲板，舱室之间用肋骨、横梁、舱壁清楚分隔，
每个舱室里是稀疏的纯黑剪影船员在岗位上，姿态疲惫佝偻；
两个舱室有微弱暖黄油灯光晕，最底层货舱深处一点磷光青；
吃水线用细锈红线标出。
纸的上方五分之一是黑暗雾海与远处灯塔的一束青光，
下方五分之一渐隐为纯黑，留给界面按钮。
配色严格限五色：深渊黑、旧纸米黄、磷光青、灯火黄、锈红。
硬边缘、扁平干净形状、缩到缩略图仍能看清舱室分隔，旧纸颗粒、墨点、重暗角，光源来自左上。
```

### 2.3 Negative（必须带，三版都靠它压住了"现代化"和"精致感"）

```
no text, no letters, no numbers, no handwriting, no watermark, no logo,
no gradients, no soft blur, no glow bloom, no photorealism, no 3D render,
no smooth vector illustration, no cartoon, no chibi, no bright saturated colors,
no modern UI, no rounded rectangle panels, no lens flare, no depth of field
```

**`no text` 是硬要求**：AI 出的任何"文字"必然是乱码，而主界面标题必须可控、可多语言、可动画。文字一律引擎排，不进图。

### 2.4 封面 / 商店页 prompt（横版，另一张已成图）

```
Wide horizontal 16:9 key art, poster composition. A lone wooden sailing ship seen from
a low front-side angle, small against an enormous wall of fog, its few lanterns glowing
warm lamp yellow. Beneath and behind the fog, a massive vague silhouette of a colossal
sea creature barely visible: a cracked dome-shaped bell and long trailing tentacles,
rendered only as a flat dark shape with a single faint phosphor cyan eye glow.
Crowquill pen ink illustration, deep-sea gothic, heavy ink shadows, fine cross hatching,
limited palette of abyss black, aged paper beige, phosphor cyan, lamp yellow, one rust red accent.
High contrast, silhouette readable at thumbnail size, aged paper texture, lighting from upper left.
```

## 3. 主界面必须分层，不能整图出

| 层 | 内容 | 出图方式 | 备注 |
|---|---|---|---|
| L0 底 | 雾海 + 灯塔（v3 顶部那条带） | AI 单出 1080×1920 背景 | 可压缩为 JPG，最省包体 |
| L1 纸 | 烧边羊皮底板（中间镂空/或整张） | AI 单出，做九宫格切片 | 拉伸不变形是难点，需手工定切片 |
| L2 剖面图 | 船体线描 + 剪影船员 | **游戏内真实剖面**，主界面用静态图 | 静态图只做"诱饵"，进游戏后切动态 |
| L3 标题 | 游戏名 | **不用 AI**，用字体 + 木刻滤镜 | 见 §4 第 1 条 |
| L4 按钮 | 3 个羊皮按钮 | 九宫格 + 代码拼 | v1 的纸太亮，需压暗 20% |
| L5 氛围 | 雾、灯闪、墨点飘落 | 程序粒子 | 0 成本，效果最大 |

**主界面只有一个真正的设计决策**：剖面图是"死的插画"还是"活的船"。建议**活的**——主界面直接复用游戏内剖面，船员在动、灯在闪。这样主界面本身就是玩法演示，同时也省掉一张静态图。

## 4. 三张图暴露的问题（按严重度）

1. **标题字形**：三张都没有字，这是对的。但项目里必须有中文标题，AI 出不了。→ 用开源字体（霞鹜文楷 / 文悦古体仿宋）+ 木刻/蚀刻滤镜处理，成本 0.5 人日。**这是唯一不能交给 AI 的静态资产。**
2. **v3 船员太"热闹"**：AI 默认把人群画成集体劳动的热闹感，与"压力会杀人"的基调相反。→ prompt 里要写 `sparse, weary, hunched, only 6-8 figures total, several compartments empty`；空舱比满舱更有压迫感。
3. **细节密度超标**：v3 的木纹、绳结、铆钉密度远高于"部件化 sprite"所需。→ 这是插画与游戏素材的天然差异。**主界面可以这么细，游戏内 sprite 必须减到 1/3 细节**，否则手机小屏糊成一片。
4. **亮部偏移**：v1/v3 的暖黄偏多，整体偏"炉火感"。→ 压到 2~3 处光斑，其余保持冷黑。
5. **水印**：本轮出图被工具自动打了"AI生成"角标。这是平台显式标识，**预览图可以，正式素材必须自己控制标识位置**（启动页声明 + 分享卡片角标），不能依赖工具水印。

## 5. 下一步（按顺序，别跳）

1. **拍板 v3 路线**（旧纸图纸 + 活剖面）。拍板后这份 prompt 就是全项目风格前缀。
2. **主界面不动手做**，先做 §3 的 L2——游戏内剖面灰盒。主界面是剖面的副产品，反过来做会返工。
3. **同步验证 sprite 侧**：用同一套前缀出 102 腐化螃蟹的 3 张部件（身体/臂/发光层），缩到 96px 看还认不认得出。**这是部件化能否成立的真判据**，比主界面重要。
4. 标题字体选型与木刻滤镜，0.5 人日，可随时插做。
