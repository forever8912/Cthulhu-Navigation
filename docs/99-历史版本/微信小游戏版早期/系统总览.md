## 一、产品定位

| 项 | 内容 |
|---|---|
| 平台 | 微信小游戏（首发）/ TapTap（同步或紧跟），PC完整版延后 |
| 题材 | 克苏鲁恐怖航海（IP源自番茄小说《恐惧之海》） |
| 核心玩法 | **辐射避难所式船只横剖面经营 + 横版挂机塔防** |
| 商业化 | IAA（激励视频）为主，无强制插屏，单日激励视频≤5次 |
| 单局体验 | 挂机收益+短时操作（拖拽调配），碎片化Session |

### 一句话概念
玩家经营一艘航行在恐怖海域的船：把船员拖进不同舱室维持船的运转，怪物从海面游来爬上船舷，船员自动迎战；在资源、恐惧与死亡之间维持平衡，击败海域Boss，驶向更深的海。

## 二、核心玩法结构

### 2.1 双层玩法

```
【经营层】船舱横剖面（类辐射避难所）
  - 房间建造/升级，船员拖拽分配岗位
  - 生产：能源（蒸汽吃木材）/食物/淡水/弹药/装备/材料
  - 维持：SAN值、伤病、特性、房间/船体耐久

【战斗层】横版挂机塔防
  - 怪物自海面游来→攀上船舷→攻击船体/船员
  - 船员全自动战斗（器械+武器），玩家不操作攻击
  - Boss=大型海怪，需SAN抗性达标后挑战
```

### 2.2 玩家唯一操作

**拖拽船员到具体舱室。** 除此之外一切自动：
- 战斗器械自动开火，船员自动攻击射程内敌人
- 生产自动进行，探索自动闯关
- 玩家的决策点 = 人事调度（快死的拖去医务室、高技巧的拖去炮位、SAN崩溃的拖去忏悔室）+ 建造升级 + 锻造/捞取等点击操作

> 【待定】是否保留1个全船紧急技能（如"鸣炮驱散"）作为高压时刻的主动操作，待原型验证后决定。

## 三、核心循环

```
挂机生产（能源/食物/淡水/弹药）
      ↓
怪物袭击 → 自动防御 → 掉落装备/材料
      ↓
资源投入 → 房间升级 / 装备锻造 / 船员治疗
      ↓
实力增长 → 挑战海域Boss → 通关结算（SAN判定→特性获得）
      ↓
解锁新海域（更强怪物/更高恐惧值）→ 新一轮循环
```

### 压力轴（4条）
| 压力 | 来源 | 失控后果 |
|---|---|---|
| 能源 | 能源房产出 vs 全船耗电（**v3.6 起全船只有一间能源房：动力舱**） | 全船停摆（总闸） |
| 食物 | 食物房产出 vs 船员消耗 | 饥饿→SAN下降→效率下降 |
| 淡水 | 水源房产出（MVP雨水收集器）vs 船员消耗 | **海上核心生存指标**：短缺→SAN持续下降+种植房停产 |
| SAN | 见《SAN与特性系统》 | 崩溃→停工/debuff→战斗失败 |

> 淡水是独立压力轴（海上淡水匮乏是重要生存指标）。  
> 弹药**不进压力轴**，只在战斗房/工坊界面显示剩余数量，耗尽则器械哑火转白刃。  
> 木材是能源+建造双重消耗品，来源：漂浮物/岛屿探索/怪物掉落。

## 五、船员与属性

### 5.1 四维属性（已收敛，砍掉敏捷）

| 属性 | 绑定 |
|---|---|
| 力量 | **近战**武器伤害（发挥率）、HP上限、重体力岗位 |
| 技巧 | **枪械**武器伤害（发挥率）、暴击率、科技器械操作、维修效率、工坊生产 |
| 智力 | **法器**魔法伤害、**枪械释放效率**、魔法器械操作、次级魔抗、仪式类 |
| 精神 | **圣典**治疗量/对亡灵伤害、SAN上限/抵抗/恢复、魔法减伤（魔抗）、忏悔室 |

> 四类主武器：近战=力量、枪械=技巧、法器=智力、圣典=精神；**主属性与效率属性必须不同**。效率属性由武器配置（当前枪械=智力，其余=技巧），`释放效率=clamp(效率属性÷效率需求,50%,200%)`。属性来源与派生公式详见《角色系统.md》（属性 SSOT）。

### 5.2 成长方式（属性经验 + 转职）
- **属性成长**：在对应属性的房间工作、战斗、锻炼室锻炼、吃特定道具 → 获得该属性经验 → 经验满提升属性值
- **转职成长**：属性达标 + 获得转职书 + 完成转职任务 → 转职，获得额外技能与属性提升；共7档，最高"神级"（后续版本开放），MVP开放前3档
- 辅助成长：装备（4槽位词缀）+ 特性（通关结算获得）+ SAN状态
- 详见《船员养成系统.md》
- 船员获取：海上漂浮物"落难船员"为主要补充方式（替代抽卡），保留稀有度概率框架（沿用旧《船员招募系统》数值）

### 5.3 船员上限规则
- **上限 = 船舱槽位数 × 2（岗位）+ 甲板战斗岗数量**
- 每个船舱房间容纳2名岗位船员；甲板战斗员初始3名，船只每升1级+1战斗岗
- 示例：1级船3船舱 → 3×2+3=9名船员；2级船6船舱 → 6×2+4=16名船员
- 船只升级在船舱界面直接进行（v3.2：船坞岛已删）

### 5.4 死亡规则
- **死亡**：生命归零即离场，不永久移除、不损失特性；复活无次数上限（见根目录 `01-系统总览.md` §5.4）
- 可通过激励视频/分享复活（复活是否保留特性/SAN状态见《SAN与特性系统》待定项）

## 七、分期路线图

### MVP（8-10周）
- 房间 13 间（不含船体）：**动力舱**（唯一能源房）、水源房、钓鱼房、种植房、瞭望台、医务室、4 组炮台、工坊、忏悔室、打捞房，另加船体 / 生命号船体（**阶数逐房不同：动力/船体 5 阶、生活线 3 阶、炮台 6 阶；每阶一个名字：升级不是加数字，是换了一个具体的东西**）
- 船员上限按"船舱槽位×2+甲板战斗岗"计算（初始3舱→9人）；压力轴=能源+食物+淡水+SAN（弹药仅显示余量）
- 属性经验获取（工作/战斗/锻炼室/道具）+ 转职前3档
- 3张海图+奇迹之海、15种怪+3个Boss
- 战斗：瞭望台+船员武器自动攻击；房间/船只耐久与修理；海中怪+登船怪
- 装备4槽4稀有度；钓鱼主动+自动；鱼类图鉴40种
- 留存：每日任务、7日登录、图鉴成就、游戏币
- IAA点位：死亡复活/离线翻倍/再捞一次；分享/广告按天递减

## 八、商业化约束（硬性）

1. IAA为主，单日激励视频≤5次/点位受频控
2. 取消一切强制插屏
3. 广告点位：死亡复活 / 离线收益翻倍 / 打捞加速 / 锻造品质保底 / 商人岛刷新 / 再捞一次 / 再抛一竿 / 游戏币获取
4. **分享/广告按天递减比例**（详见《日常与留存系统》）：
   - 分享/广告点位为"分享/看广告/游戏币"三选一，禁止强制分享；默认高亮顺序按登录天数递减（D1 80/20 → D7+ 20/80，仅影响默认项）
   - 死亡复活点位始终优先分享
5. **游戏币永远稀缺**：锻造/购买/清特性都消耗游戏币，迫使玩家看广告获取
6. 恐怖题材与微信用户池存在错位风险：美术上"阴森氛围+梗道具名"调和，不做血腥跳吓
