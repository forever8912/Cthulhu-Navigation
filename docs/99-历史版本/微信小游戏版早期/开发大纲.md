# 《恐惧之海》微信小游戏版 - 开发大纲

## 项目概述

### 游戏名称
恐惧之海（微信小游戏版）

### 游戏类型
克苏鲁风格像素风航海生存游戏（IAA广告变现）

### 目标平台
微信小游戏

### 开发周期
4-6周

### 核心体验
快速上手、即时满足、恐怖氛围、广告变现

### 灵感来源
基于**原创克苏鲁航海世界观**（见 `设定\世界观.md` v2.0），简化适配微信小游戏

## 游戏功能概述

### 核心玩法功能

1. **航行系统**
   - 虚拟摇杆控制航向
   - 风向系统：实时风向影响速度
   - 迷雾导航：能见度20-30米
   - 自动航行：点击目标点自动航行

2. **资源管理系统**
   - 基础资源：木材、铁、贝壳币
   - 特殊资源：神秘碎片、秘银、神器碎片
   - 存储限制：船只载重有限

3. **恐惧值系统**
   - 恐惧值：0-100范围
   - 轻度幻觉(70-50)：视野轻微下降
   - 中度幻觉(50-30)：出现虚假敌人
   - 重度幻觉(30以下)：控制失灵

4. **岛屿探索系统**
   - 3种岛屿类型：荒岛、渔村废墟、遗迹岛
   - 迷雾视野限制
   - 随机事件：战斗、资源、NPC、宝箱
   - 资源收集

5. **战斗系统**
   - 冲撞攻击：近战物理伤害
   - 炮击：远程攻击
   - 技能攻击：特殊能力
   - 逃跑机制：战斗风险高，优先规避

6. **技能系统**
   - 3种职业，各3个技能
   - 主动技能：需要释放
   - 被动技能：持续生效

7. **升级系统**
   - 属性升级：力量、敏捷、精神
   - 技能升级：提升效果
   - 船只升级：船体、帆、武器

8. **广告系统**
   - 激励视频广告
   - 复活广告
   - 奖励翻倍广告
   - 跳过战斗广告

9. **社交系统**
   - 好友排行榜
   - 邀请好友奖励
   - 分享功能

10. **剧情系统**
    - 主线剧情：收集神器碎片
    - 三种结局：救赎、深渊、统治
    - 简单分支选择

## 技术方案

### 引擎选择
- **Cocos Creator 3.x**：成熟的小游戏生态，性能优异
- **微信小游戏原生框架**：轻量级，快速上手

### 美术风格
- **像素风格**: 复古8-bit/16-bit像素艺术
- **色调**: 昏暗阴暗，深蓝、深绿、黑色为主
- **特效**: 像素化迷雾、动态海浪、闪烁灯火
- **UI**: 简洁直观，适配手机屏幕

### 音效设计
- 复古芯片音乐风格背景音乐
- 船体吱呀声、海浪声、风声
- 远处低语、怪物咆哮
- 突然寂静的恐怖感

### 资源策略
- 程序化生成岛屿和海域
- 复用敌人模型和动画
- 使用纹理切换实现不同状态

## 核心循环

```
开始游戏 → 选择职业 → 航行探索 → 遭遇事件
→ 获得奖励 → 升级船只/技能 → 触发广告/分享
→ 继续探索 → 击败Boss → 完成结局
```

## 单局流程

### 开场（1分钟）
- 游戏标题动画
- 职业选择
- 新手引导

### 航行（3-5分钟）
- 选择海域
- 自动航行
- 随机事件

### 探索（2-3分钟）
- 登岛探索
- 遭遇事件
- 获取资源

### 战斗（1-2分钟）
- 遭遇怪物
- 使用技能
- 获得奖励

### 升级（1分钟）
- 升级属性/技能/船只
- 触发广告

### 循环
- 重复航行→探索→战斗→升级

### 结局（2分钟）
- 击败最终Boss
- 展示结局
- 分享邀请
