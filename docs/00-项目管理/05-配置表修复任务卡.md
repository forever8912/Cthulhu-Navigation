## 一、背景与判定

导出器 `tools/配置导出/export_config.py` 已改为**阻断式校验**：任一单元格无法按说明行的类型标记解析，就返回非零退出码且**不写出任何 JSON**。

当前全量导出退出码 **1**，共 **225 处**阻断错误。**这 225 处全部是源表缺陷，导出器没有误判**，因此修复对象是 `data/配置表/*.xlsx`，**不要改导出器**。

### 错误分布（2026-10-31 实测）

| 工作簿 / 工作表 | 处数 | 根因 | 任务卡 |
|---|---:|---|---|
| `01_海域与关卡` / `事件选项表` | 110 | `H2` 说明标 `[int]`，数据是 `RS-W1A-OK` | FIX-A |
| `01_海域与关卡` / `事件表` | 8 | `A2` 说明标 `[int]`，8 个事件 id 是 `W01`/`T01`… | FIX-A |
| `11_竞技场` / `层数锚点表` | 2 | 第 14 行是一整行中文注释，混在数据区 | FIX-A |
| `04_房间与生产` / `房间等级表` | 100 | 第 2 行说明整体错位，4 列类型标错 | FIX-B |
| `04_房间与生产` / `船体等级矩阵` | 2 | 第 8 行 `格数`/`甲板岗` 值是「待定」 | FIX-B |
| `03_物品与掉落` / `物品表` | 3 | `I` 列 `use_effect` 被写成中文注释 | FIX-C |
| **合计** | **225** | | |

### 派发原则

按**文件**切分，保证独占写入范围不重叠，三张卡可并行：

| 卡 | 独占写入文件 | 处数 | 难度 | 是否需裁决 |
|---|---|---:|---|---|
| FIX-A | `data/配置表/01_海域与关卡.xlsx`、`data/配置表/11_竞技场.xlsx` | 120 | 低 | 否 |
| FIX-B | `data/配置表/04_房间与生产.xlsx` | 102 | 高（要重建说明行） | 否 |
| FIX-C | `data/配置表/03_物品与掉落.xlsx` | 3 | 低 | **是** |

**共同铁律（三张卡都适用）**

1. 只改本卡点名的单元格。**数据值一个字符都不许动**（唯一的例外是 FIX-B 第 8 行的「待定」，见卡内说明）。
2. 不许新增/删除列，不许调整列顺序，不许改列名（`第 1 行`）。
3. 不许改 `tools/配置导出/` 下任何文件。
4. 改前先备份原文件到 `.tmp_backup/`，改后做**全簿逐单元格比对**，把差异清单贴进交接报告，差异数必须等于本卡声明的数量。
5. 每张卡改完必须自己跑一次全量导出，报告退出码与剩余错误数。
6. xlsx 保存用 `openpyxl`，不要在其他进程里同时打开该文件。
