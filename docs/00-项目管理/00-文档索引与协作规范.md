1. 读仓库根目录 `AGENTS.md`

## 7. 已确认的核心决策（不得静默推翻）

| # | 决策 |
|---|---|
| 1 | 玩法 = 辐射避难所式船舱横剖面经营 + 横版挂机塔防；怪物从远海出现，穿过射程带游向船舷再攀爬登船 |
| 2 | 玩家高频操作 = 拖拽船员到舱室；器械/战斗全自动；不给直接攻击操作。全船**仅有 2 个主动技能**（每场各 1 次）：**全员参战**（生产岗上甲板，产出停摆+食物消耗×3）与**传送逃跑**（读条8s、持续耗能源、读条结束才生效） |
| 2.1 | **战斗数值按塔防口径**：远程在怪物进射程后即开火，近战必须等它登船。射程带 炮位95/枪械65/法器55/近战20，普通怪海面击杀率锁 65%（见《战斗系统》1.3 + 《怪物系统》1.2） |
| 3 | 士气不做全局值，改每角色独立 SAN |
| 4 | SAN"越打越麻木"：同种怪惊吓递减；后期Boss恐惧值更高，需抗性达标 |
| 5 | **死亡 = 生命归零后本场离场**，不永久移除、不损失正面特性、不产负面特性；复活无次数限制（广告 / 200贝壳币 / 等待60s 三选一），复活后 SAN 归30、HP 回50% |
| 6 | 属性收敛为4维（力量/技巧/智力/精神），砍敏捷 |
| 7 | 岗位效率 = 属性÷需求，达标100%，线性加成封顶200% |
| 8 | 成长 = 属性经验 + 转职（属性达标+转职书+转职任务），7档，MVP三转 |
| 9 | 职业按神系设计，多个低级职业指向同一上位神明 |
| 10 | 装备 = 暗黑式随机掉落为主 + 锻造为辅，不做宝石系统 |
| 11 | 淡水是独立压力轴；弹药只显示剩余数量，不进压力轴 |
| 12 | 蒸汽档动力消耗木材（木材 = 能源+建造+修理三重消耗） |
| 13 | 海中怪攻击房间→损毁→继续攻击扣船只耐久→归零失败；船员自动修理耗木材，技巧越高越快 |
| 14 | **战败（船只耐久归零）不致死**：资源类遗失30-50%、全员扣当前HP上限35%（最低留1）、全员SAN-15、房间与船体耐久重置为30%、**章节进度重置**（可反复刷资源再战）；装备/特性/等级全部保留 |

| 16 | 船员上限 = **已建房间数×2** + 甲板战斗岗（初始3，船体每级+1，Lv5=7） |
| 17 | 主线 = 击败畸变神明拯救世界；奇迹之海 = 无限关卡冲里程，后期打隐藏神明 |
