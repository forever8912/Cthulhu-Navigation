## 〇、这张图要回答的三个问题

上一版图（GPT 生成）失败在结构：房间被"画"进船壳、无舷、无甲板分区、无攀爬载体，读者看不出战斗怎么发生。本图必须以**可读的空间**回答：

1. **怪从哪上来？** —— 必须有可见的攀爬载体（锚链/绳梯/舵叶），且每条载体对应一个落点。
2. **人在哪能打到它？** —— 甲板战斗岗必须站在不同高度，形成"高打远、平打贴、低打水下"的射界差。
3. **炮在哪能打到它？** —— 塔位必须与**炮门**对齐，炮口朝向可读；空炮门要能被认出是"还没建"。

## 一、船型决策：Lv1 由「木筏」改为「单桅小渔船」

《01》§四船体矩阵里 Lv1 名为"木筏"，但三条硬逻辑与之冲突，参考图无法成立：

| # | 冲突 | 说明 |
|---|---|---|
| 1 | **没有"舷"** | 战斗流程写死"攀上船舷"，木筏干舷近零，怪物是"跨上来"不是"爬上来"，攀爬 2.4s 窗口失去载体 |
| 2 | **没有"舱"** | 木筏无甲板下空间，8 格舱位无处安放，塔防的垂直分层塌成一张平面 |
| 3 | **没有垂直射界** | 木筏全船等高，火枪俯射 / 舷墙平射 / 炮门低射的三层射界无法表现 |

**建议**：Lv1 定名 **「近海小渔船」（单桅、单层甲板、带艉楼）**，长 ≈ 4.5 舱格、干舷 1.2 格、舱深 2 格、吃水 0.6 格。木筏降级为 Lv0 教学关过场（不参与战斗）。→ 待同步修订《01》§四矩阵、`船舱房间系统` 船体表（建议记 v1.16）。

## 二、空间逻辑（提示词的全部依据）

### 2.1 垂直分层（横版侧视，船首朝左）

| 层 | 画面高度 | 内容 | 战斗含义 |
|---|---|---|---|
| L1 远海 | 68%~78% | 雾、出现线、远山剪影 | **保持空旷**，留出怪物出现线，禁画巨物遮挡 |
| L2 近海/水线 | 78%~84% | 浪、吃水线、舵叶露出一角 | 水下威胁带，怪物在此环绕 |
| L3 舷外 | 78%~88% | 舷侧板、炮门、拖网 | 贴船怪的攻击与攀爬起点 |
| L4 甲板 | 74%~80% | 前甲板 / 主甲板 / 艉楼（高 0.6 格） | 3 个战斗岗，高度差 = 射界差 |
| L5 内舱 | 80%~96% | 2 行 × 4 列 = 8 格，横剖面可见 | 塔位 + 生产位，被入侵时是死亡陷阱 |

> 设计要点：内舱**下半部低于水线**（真实货舱如此），所以舱底有水渍、舱壁有湿痕——这一笔让"船"立刻可信。

### 2.2 三条攀爬路径（每条都要有物理载体）

| # | 载体 | 起点 | 落点 | 压力性质 |
|---|---|---|---|---|
| P1 | **船首锚链**（从锚机垂下入水） | 水面 | 前甲板 | 最快、最近炮位，第一波压力 |
| P2 | **舷外拖网 + 绳梯**（网里还有渔获，湿漉漉） | 水面 | 主甲板**舱口旁** | 直插舱口，最危险 |
| P3 | **舵叶 + 一根垂到水里的旧缆绳** | 水面 | 艉楼下方 | 绕后，最高点失守 |

> 每条载体都必须"可被抓握"：锚链有链环、绳梯有横档、拖网有网目。这是玩家一眼读出"这里会被爬"的唯一依据。P4（断桅帆索高空荡入）留第二章。

### 2.3 攻击位与射界（高度差即玩法）

| 位 | 位置 | 高度 | 能打 | 打不到 |
|---|---|---|---|---|
| A1 | 艉楼（舵轮旁） | 最高 | 甲板全域 + 舷外近距（俯射） | 水下 |
| A2 | 主甲板舷墙后 | 中 | 贴船舷外、水面 | 远海 |
| A3 | 前甲板绞盘旁 | 中 | 正前方向、锚链落点 | 船尾方向 |
| A4 | 桅顶吊斗（瞭望台） | 最高 | 远海出现线 | 贴船、甲板死角 |
| **B1** | **舱内 2001 鱼叉炮**（1 格） | 低 | 舷侧水面、贴船怪（从炮门平射） | 远处、高处 |
| B2 | 舱口（甲板开口） | 中 | 钻进舱内的怪（向下打） | 舷外 |

> 核心博弈：**A4 打远打不到近，B1 打近打不到远，A1 最高但只有一个站位**。玩家必须为"远/中/近/舱内"各配资源——这正是船舱剖面的存在意义。

### 2.4 炮位口径（重要纠偏）

- **只用 1 门在用的炮**：`2001 手掷鱼叉炮`，占 1 舱格，炮架从**左舷中间炮门**伸出，炮口朝左，叉架上绑 5 根鱼叉。
- **另 2 个炮门用木板封死**（可见铁钉、木条、锈迹）——它们是 Lv2/Lv3 的 `2004/2003/2002` 塔位。**空炮门 = 可见的成长空间**，比画两门白送的炮更有信息量，也符合 v1.15"船不白送火力"。
- **艉楼与甲板不放固定炮**。甲板只有人、绞盘、缆绳、吊杆。

### 2.5 舱格与船形的贴合（"舱体按实际空间设置"）

- 内舱不是矩形盒子，而是**两端收窄的梯形内腔**：船首段舱顶随首弧下沉，船尾段舱底随艉弧上收。
- 8 格**等大**（4 列 × 2 行），但**船首列上格**与**船尾列下格**各被船体弧线切掉一角——格子在，形状不齐，这才像船。
- 格子之间是**可拆卸木框模块**，模块间留 2px 缝，不画连通墙体。
- 已建 4 格：动力舱（脚踏轮，与舷侧轮轴对齐）、种植房、雨水收集器、**2001 鱼叉炮（与中间炮门对齐）**；空槽 4 格露木框与钉子。

### 2.6 甲板布局（左→右）

艏斜桅 + 锚机（0~0.8 格）→ 前甲板：绞盘、缆绳盘、A3 岗（0.8~2 格）→ 主甲板：**舱口**（0.8 格宽，木盖半开）、吊杆、A2 岗（2~3.5 格）→ 艉楼（+0.6 格）：舵轮、A1 岗、小舱室（3.5~4.5 格）；单桅立于 2.2 格处略后倾，桅顶吊斗 = 瞭望台。

## 三、构图规范（两套共用）

| 项 | 规定 |
|---|---|
| 画幅 | **固定横版 16:9**，出图 1536×864 或 2048×1152；设计画布 1280×720。**不做竖屏、不做长屏适配** |
| 安全区 | HUD 与核心战斗区收进**中央 2.2:1**，仅为给不同横屏长宽比留余量，与竖屏无关 |
| 船位 | 右侧 **61%**（x≈500~1280），船首朝左；船长 ≈780px |
| 水面线 | 画面高度 **78%** |
| 比例尺 | 单舱格 ≈160×160px；**船员身高 = 舱格宽的 1/3（≈48px）** |
| HUD | 顶部 12% 深木+黄铜底槽，**只画框架与图标位，不写任何文字与数字** |
| 按钮 | 左缘竖排 4 个方形（建造/船员/背包/设置）；右下 2 个圆形技能键 |
| 光 | 舱内暖黄灯（3 处）vs 舱外冷雾，冷暖分界在水线 + 舷墙 |
| 怪物 | 仅 2 只入画：半透明磷光水母（远海）+ 腐化螃蟹（正抓锚链）。**禁巨物、禁触手、禁血腥** |

## 四、提示词 A —— HD-2D（像素化厚涂）

> 定义：**统一像素网格 + 24~32 色有限色板 + 1px 硬描边**；"高清感"来自**分层光照、体积雾、水面反射、粒子**，而不是提高分辨率。
> ⚠️ 最容易翻车的点：AI 会画成"高清插画上贴像素角色"。所以必须强调"全图同一像素密度"。

## 五、提示词 B —— 暗黑手绘卡通（粗描边）

> 定义：**手绘厚涂 + 4~6px 粗黑描边 + 高对比有限色**（《暗黑地牢》/《饥荒》/《克苏鲁的呼唤》一路）。剪影优先，笔触可见。
> ⚠️ 最容易翻车的点：AI 会画成"矢量扁平"或"厚涂写实"。必须压住这两头。

### B-1 中文（完整，可直接贴）

```
2D 横版侧视游戏主界面示意图，暗黑手绘卡通风格（粗黑描边、厚涂笔触、剪影优先），克苏鲁恐怖航海题材，16:9。

【风格规范·最高优先级】手绘感：每个物体都有 4~6px 的粗黑描边（深墨色 #12100E，不是纯黑），轮廓线有粗细变化与断裂；内部是厚涂色块，可见干刷笔触与纸纹颗粒；暗部压缩到接近黑，光源单一且明确；有限色板、高对比、低饱和。不要矢量扁平、不要 3D、不要写实照片感、不要干净的数字绘感。

【构图】画面右侧 61% 是一艘近海小渔船的完整侧视横剖面，船首朝左；左侧 39% 是开阔雾海，海面延伸至远处雾中的怪物出现线，该区域保持空旷。水面线位于画面高度 78%。顶部 12% 是深色木质加黄铜的 HUD 底槽，只画框架与图标凹槽，不写任何文字数字。左缘竖排 4 个方形功能按钮，右下角 2 个圆形技能按钮。

【船体·必须像船】单桅单层甲板小渔船：船首有明确的弧线与艏柱，斜向左上的艏斜桅，外倾的舷侧板用横向木板拼成；干舷约 1.2 个舱格高，舷墙是带缝隙的木栏板；吃水 0.6 格，水面有吃水线与泡沫；船尾方形艉板，舵轮与入水的舵叶。船体是斑驳旧木、补丁帆布、锈铁件与藤壶，边缘有毛糙的手绘线。绝不是木筏、不是大帆船、不是蒸汽船。

【甲板布局·从左到右】船首锚机与垂入水中的粗铁锚链；前甲板有绞盘、盘好的缆绳、一名持弯刀的水手；主甲板中央一个 0.8 格宽的木舱口，舱盖半开露出向下的梯子；单桅略后倾，桅顶一个木吊斗；船尾抬起 0.6 格形成艉楼，上有舵轮与一名持火枪朝左的水手。甲板共 3 名水手，身高约等于单个舱格宽度的 1/3；他们的剪影要有辨识度（斗篷、雨帽、绑带），面部只留极简几笔。

【内舱剖面·关键】甲板下方是两行四列共 8 个等大舱格，每格是独立可拆卸的木框模块，模块之间留 2px 缝、不画连通墙体。内舱不是矩形盒子：船首段舱顶随首弧下沉、船尾段舱底随艉弧上收，形成两端收窄的梯形内腔；船首列上格与船尾列下格各被船体弧线切掉一角。已建成 4 格：① 动力舱——四人脚踏轮连着舷侧桨轮轴 ② 种植房——木箱苗床与藤架 ③ 雨水收集器——倾斜木斗与接水桶 ④ 手掷鱼叉炮——木炮架、成捆的 5 根鱼叉，炮身从左舷中间炮门伸出，炮口朝左。其余 4 格是空木框，可见钉子、横撑、蛛网与积灰。

【炮门】左舷水线以上约 0.5 格高处开 3 个方形炮门，间距 1 格：中间一个打开并伸出鱼叉炮；左右两个用木板斜钉封死，铁钉、木条、锈迹清晰——是被封住的空位，不是火炮。

【攀爬载体·必须清晰可辨】三条通往甲板的物理路径：① 船首垂下入水的粗铁锚链，链环粗大清晰，一只腐化螃蟹正抓着它往上爬，蟹壳破碎处透出磷光青 ② 船舷外挂着湿漉漉的拖网与一架木绳梯，绳梯横档分明，网里还有几条僵死的鱼 ③ 船尾舵叶旁垂着一根旧缆绳浸在水里。

【怪物】仅两只：左前方水里一只半透明发光水母（磷光青伞体、灵紫外缘），远处雾中只有极淡的剪影。怪物要有"怪诞而非血腥"的设计感：不对称、多眼、关节错位。不出现巨大触手、不出现血肉断肢、不出现惊跳鬼脸。

【光照与色板】夜海：深墨蓝、旧木褐、苔绿、骨白，舱内 3 处暖黄提灯（动力舱、种植房、艉楼）形成三团暖光，舱外冷雾用冷灰蓝大面积压暗；磷光青 #4FD1C5 只用于水母、蟹壳裂隙与水线反光，灵紫 #A78BFA 只用于远处魔法微光。冷暖对比强烈，暗部大面积沉底，亮部只留在灯下与舷墙边缘。

【氛围】阴森、潮湿、腐朽，雾里有沉船桅杆与礁石的黑色剪影；整体像一本被海水泡过的航海日志插图；不血腥、不跳吓。
```

## 七、出图顺序与验收红线

### 7.1 顺序

1. **A-1 干净版**（HD-2D）→ 定风格基调
2. **B-1 干净版**（暗黑手绘）→ 同构图对比
3. 拍板风格 → 拿定稿垫图出**标注版**
4. 标注版通过 → 拆成三层资产：场景层（船+海+怪）/ UI 层 / 房间模块层

### 7.2 验收红线（任一条不过就重画，别修）

| # | 红线 | 判定 |
|---|---|---|
| R1 | **8 格可见且可拆** | 能数出 4 实建 + 4 空框，格子间有缝 |
| R2 | **船型正确** | 有干舷、艏柱、艉板、舵；不是木筏 |
| R3 | **三条攀爬路径可辨** | 锚链/绳梯/缆绳都能看出"能抓握" |
| R4 | **炮只有 1 门 + 2 个封板** | 不出现两门白送的舷炮 |
| R5 | **三层射界成立** | 艉楼高、甲板中、炮门低，高度差肉眼可见 |
| R6 | **船员 ≈ 舱格宽的 1/3** | 不能是 1/2 |
| R7 | **16:9 且 HUD 无字** | 无任何文字/数字 |
| R8 | **远海留空** | 无巨物、无触手遮挡出现线 |

### 7.3 如果 R1/R5 反复失败

说明 AI 在"把结构烧进画面"。**止损方案**：让 AI 只出**氛围层与材质**（雾、水、灯光、怪物、船体表面），船的剖面结构与 8 格槽位改由引擎用木框图块拼装——这也是正式生产该走的路。参考图的作用是"证明好看"，不是"证明能做"。
