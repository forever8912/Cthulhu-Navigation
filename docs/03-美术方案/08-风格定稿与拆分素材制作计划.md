> 版本：v1.8（2026-10-31）

## 一、结论

当前风格定稿适合作为第一章船上主场景的**视觉北极星和回拼验收基准**。它已经有效统一了横版船体剖面、冷海暖船、旧木锈铁、雾中远船、局部灯火、海面磷光和铜木 UI 等关键语言，可以在此基础上进入正向拆分制作。

它是一张扁平场景效果图，不是可直接切片的运行时图集。被栏杆、船板、海水、人物和器械遮挡的区域没有完整结构；直接抠图会造成动画露洞、光影烘焙冲突、锚点不一致和尺寸不可复用。因此本计划采用：

```text
定稿场景作蓝图 → 独立重绘完整部件 → 统一原点与光照 → 回拼复现场景 → 实机缩放验证 → 用户批准后入工程
```

### 1.1 当前进度与结论

- Gate A 结构布局已批准，生成授权已记录。
- `ship_lv1_hull_shell_v001` 与 `ship_lv1_hull_frame_v001~v004` 已生成，但均为 `REWORK`，不是正式素材。
- 三版框架都有真实 Alpha 和六舱开口，但按批准格宽换算后的船员净高约 109~111px，低于 112px；分层和完整回拼也未完成。
- v004 的精确底稿已通过，但生成候选的六个净空区均被梁柱侵入；这证明整张候选生成无法承担硬几何约束。
- v005 固定几何分层母版已通过六区 Alpha、坐标、原点和净高检查；几何路线成立并冻结。
- v005 材质仍是规则化矢量初稿，缺少厚涂笔触、体积明暗和旧化变化，材质评审为 `REWORK`。
- v006 在冻结几何下完成材质替换，技术检查零漂移；但与风格定稿并排复核后，材质尺度、橙锈/金色高光和粗重笔触明显偏离母版，材质结论更正为 `REWORK`。
- 下一步不再直接制作完整船体：先交付旧木、结构边和少量锈铁的小块材质样板，用户批准后才映射到 v007。
- 整张船框候选生成路线继续关闭；批准前不得进入最小拆分样例或 Cocos 导入。

## 二、母版的作用边界

### 2.1 由母版冻结

- 16:9 横版、船体侧视剖面与“上甲板 + 下船舱”的主要阅读方式。
- 低饱和蓝灰海天与旧木暖褐船体的冷暖关系。
- 木、铁、绳、帆布、盐渍和潮湿表面的厚涂材质语言。
- 船体为中高对比，人物/武器/怪物为最高对比，远景船影与雾最低对比。
- 人类安全与生产区域使用小范围暖灯；海怪/异常可使用克制的青紫磷光。
- UI 使用深色木板、旧铜铆钉、机械圆盘和航海器件的装饰语汇。
- 恐怖主要来自深海、雾、尺度与未知生物，不使用血腥或跳吓。

### 2.2 不由母版冻结

- 房间最终数量、舱格宽度、炮位和楼梯的玩法坐标。
- 碰撞框、触控热区、动画幅度、关节位置与部件数量。
- 船体 Lv2/Lv3 的新增结构和所有房间的最终功能布局。
- 正式 HUD 信息架构、文字、图标含义和安全区。
- 运行时纹理尺寸、图集组合、压缩格式和性能预算结论。

若视觉复现与玩法可读性冲突，先保证玩法和触控，再用构图、材质与光色恢复母版气质；不得为了像原图而牺牲交互。

## 三、正向拆分原则

1. **重绘而非抠图**：母版只提供结构、色彩和材质参考；每个正式部件必须包含被遮挡的完整区域。
2. **先结构后装饰**：先确定舱格、甲板、水线和锚点，再画藤壶、裂纹、绳结和小道具。
3. **共享逻辑画布**：同一角色、怪物、炮位或房间部件使用共同原点、比例与光向。
4. **光照分离**：资产保留可复用的中性体积光；灯火辉光、月光染色、水下青光优先单独成层。
5. **前后遮挡明确**：至少区分背后结构、交互主体、前挡板/栏杆和特效遮罩。
6. **实际尺寸评审**：母版可以高分辨率绘制，但必须同时查看 96~128px 逻辑显示下的轮廓与接缝。
7. **版本可追溯**：定稿原图不覆盖；所有候选、拆件、回拼图和人工修整均写入 manifest。

## 四、建议层级与素材清单

### 4.1 环境层

```text
bg_sky_moon                 天空、云层、月亮
bg_ship_silhouette_far      远处船影与岛影
bg_fog_mid                  中景雾带
bg_sea_far                  远海
bg_sea_near                 近海与水线
fg_wave_foam                前景浪花/船边泡沫
fg_underwater_haze          水下暗部、气泡与磷光氛围
```

雾、浪花和水下辉光必须能独立调色或关闭。远景不得烘焙进船体，避免镜头轻移时完全静止。

### 4.2 船体 Lv1

```text
ship_lv1_back_structure     后层梁柱、内壁
ship_lv1_hull_main          完整船壳与甲板主体
ship_lv1_room_mask          舱室开口/裁切遮罩
ship_lv1_front_planks       前挡船板
ship_lv1_rail_rope          前景栏杆、绳网、梯子
ship_lv1_mast_sail          桅杆、破帆、吊具
ship_lv1_damage_overlay     可选破损/潮湿覆盖层
ship_lv1_light_overlay      局部灯光与水面反光
```

船壳必须在水线以下留出足够完整区域，水浪不能与主体烘焙在同一层。船头、船尾和舱室边界先按玩法网格校准，再做旧化。

### 4.3 代表性房间与鱼叉炮 `2001`

代表房间先做“基础舱室 + 鱼叉炮位”母版，用来验证房间模板能否复用。

```text
room_base_back              房间后墙与暗部
room_base_floor_beam        地板、梁柱、边框
room_props_static           木箱、桶、工具等静态道具
room_light_overlay          灯与局部光
tower_2001_base             炮座
tower_2001_barrel           炮身/鱼叉发射器
tower_2001_harpoon          鱼叉
tower_2001_rope             绳索或收线结构
tower_2001_fx_mask          炮口、水花、命中效果遮罩
room_front_occluder         前景挡板/栏杆
```

炮口方向与旋转中心必须单独记录。第一座塔就是船体 Lv1 可建的 `2001` 鱼叉炮，不新增免费固定舷炮。

### 4.4 普通船员母版

首个船员建议使用 6~8 个部件：躯干、头、前/后臂、前/后腿、工具/武器、可选帽子。脚底中心为锚点，默认朝右；帽檐、手和武器不得与躯干熔成无法旋转的一层。

### 4.5 普通海怪母版

优先选择接近母版中“水下发光生物”的普通怪，使用主体、前后触手/肢体、发光层、水面接触层和阴影 5~8 个部件。轮廓先于表面纹理，青紫光只做局部危险信号。

### 4.6 UI 样式板

首轮只制作结构样式，不锁定正式功能：顶部木铜框、侧边方形按钮、右下圆形操作按钮、普通/按下/禁用三态。文字和功能图标保持独立，不烘焙进框体。

## 六、制作顺序与闸门

### Gate A：结构灰盒

- 在母版上标注水线、船体外轮廓、甲板、舱格、角色基准高和 UI 安全区。
- 输出无材质的色块回拼，确认玩法空间和画面比例。

### Gate B：材质母版

- 完成船体、一个房间、一个炮位、一个人物和一个怪物的厚涂母版。
- 同时输出彩色图、黑白剪影、实际尺寸和中灰底审核图。

### Gate C：部件与动作验证

- 补全遮挡区域，标记统一原点、旋转中心、前后层级和默认朝向。
- 至少用静态姿态模拟 idle/attack 两个极限位置，检查露洞和接缝。

### Gate D：回拼批准

- 使用独立部件重新拼回完整场景，不得直接叠回原始母版像素。
- 用户确认构图、气氛、材质和可读性后，将通过项升为 `APPROVED`。
- 只有通过项才允许复制到 `E:\devfearfulsea\NewProject\assets\art\` 并安排 Cocos 导入测试。

## 九、风险与后续实测

- 原图细节密度较高，缩到手机后可能造成船体噪点过多；首批必须以实际尺寸审核决定删减比例。
- 结构边较明确，应保留“雕刻/旧木边缘”的厚薄变化，避免后续资产变成统一粗黑描边。
- 当前船舱开口数量与最终 6 房布局不完全等同；Gate A 必须先用玩法网格校准。
- UI 仅定风格，不代表最终信息架构；正式 UI 仍需结合触控热区与安全区设计。
- 1672×941 是效果图尺寸，不等于运行时纹理规格；最终格式与图集分组须在 Cocos 导入测试后决定。
